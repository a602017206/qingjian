你可能还想知道

需要注册账号或保持联网吗？

不需要云端账号即可在本地创建和编辑笔记，断网也能使用。远程同步需要你自己的仓库账号与网络连接。

Git 同步等于实时多人协作吗？

目前不提供实时多人协作、完整评论或权限系统。不同笔记可自动合并，同一笔记的冲突需在应用内核对双方版本后处理。前台自动同步目前仅在测试构建提供。

能完整还原所有 Notion 内容吗？

可以导入导出包中可恢复的页面、正文与表格。源文件未包含的属性类型、颜色、评论、权限、公式和关联信息无法凭空恢复，导入报告会说明边界。完整往返迁移请使用轻笺结构化备份。

官网主题和语言也适用于客户端吗？

这里的三套主题和中英三语言为官网设计。客户端目前提供浅色、深色、跟随系统，以及简体中文和繁体中文，正文保留原始语言。
