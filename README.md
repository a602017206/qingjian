# 轻笺

一个本地优先的跨平台笔记工具，参考 Notion 的页面与内容块交互。桌面、安卓和苹果移动端使用同一套界面和同一个 Rust 核心，笔记通过多个独立 Git 仓库保存与同步。

默认界面为简体中文，提供繁体中文设置，并保留可扩展的国际化字典。所有项目说明和每日记录使用中文；代码标识、命令、依赖及运行配置使用英文。

## 已实现的首版功能

- 页面树、子页面、收藏、标签、复制、封面、图标、宽版、锁定和回收站。
- 文本、三级标题、列表、待办、引用、提示框、代码、分隔线、折叠块、简易表格、图片和附件。
- 斜线菜单、块拖动与顺序调整、格式预览、撤销与重做、页面链接、反向链接和目录。
- 数据库表格、看板、列表、图库和日历，支持多选、基础公式、关联汇总、记录正文与计算结果导出。
- 自动保存、异常恢复草稿、多个独立工作区、本地版本历史、HTTPS 仓库连接、克隆、快进更新和普通推送。
- Notion 导出压缩包、Markdown、CSV、HTML 导入；保留子页面、内部链接和附件，提供迁移报告。
- 轻笺备份完整导入导出，以及单页 Markdown 导出、主题设置和真实磁盘统计。

当前不包含实时多人协作、评论权限系统和完整的 Notion 公式语言。具体边界见 [产品设计与功能范围](docs/产品设计与功能范围.md)。

## 本机运行

需要安装 Node.js、Rust 和所在系统的 Tauri 桌面依赖。网页开发预览和桌面应用共享业务实现，但分别使用开发数据目录和应用数据目录。

```bash
npm ci
npm run dev
```

随后打开 `http://127.0.0.1:3415`。开发笔记位于项目 `.data/`，该目录不会进入源码仓库。

运行原生桌面应用：

```bash
npm run desktop:dev
```

构建当前桌面平台的正式应用：

```bash
npm run desktop:build
```

**移动端原生编译和构建只在 GitHub 流水线执行。** 本机仅编写共享代码、验证核心和界面；不要在本机执行移动端编译。现有流水线可生成安卓调试安装包和苹果模拟器应用，尚未关联远程仓库，因此还未实际执行云端构建。

## 验证

```bash
cargo test --locked -p notebook-core
cargo clippy --locked -p notebook-core --all-targets -- -D warnings
npm test
npm run check
npm run build
npm run test:e2e
npm run test:e2e:database
node scripts/check-docs.mjs
```

界面测试使用独立的数据目录，不修改用户笔记；需要可用的测试浏览器，持续集成会自动安装。详细结果见 [验证报告](docs/验证报告.md)。

## 每日记录

每次设计、修改、优化和修复追加到当天唯一记录文件，文件名包含日期、首次记录时间和内容概述。追加工具使用北京时间：

```bash
node scripts/record-change.mjs "功能修复" "说明原因、修改内容及验证结果"
```

同一天会复用原文件并追加，跨天才创建新文件。协作约定见 [项目约定](AGENTS.md)。
