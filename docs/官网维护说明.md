# 官网维护说明

公开地址：[轻笺官方网站](https://a602017206.github.io/qingjian/)。源码与客户端在同一仓库，网站独立放在 `website/`，GitHub Pages 只发布该目录，不发布笔记、测试数据或其他源码。

## 文件与本地预览

| 文件 | 用途 |
| --- | --- |
| `website/index.html` | 可直接阅读的简体中文页面、产品介绍与下载链接 |
| `website/styles.css` | 纸白、夜航、青庭主题与桌面、手机布局 |
| `website/i18n.mjs` | 简体中文、繁体中文、英文完整字典 |
| `website/app.mjs` | 语言、主题、截图分类、放大、导航与偏好记忆 |
| `website/scene.mjs` | Three.js 纸页、轨道、粒子，主题材质及暂停与降级 |
| `website/assets/` | 标识及仓库真实匿名截图的 WebP 副本 |
| `website/vendor/three/` | 固定版本 0.180.0 的 Three.js 模块与 MIT 许可证 |
| `.github/workflows/pages.yml` | 独立官网验证与 Pages 发布 |

运行 `python3 -m http.server 4318 --directory website`，打开 `http://localhost:4318`。无需编译，也不启动客户端的 Rust 服务。测试脚本使用自己的随机端口，避免与应用服务争用。

## 内容与真实功能边界

网站首次发布时核对正式版为 0.0.6，源码与新测试构建为 0.0.7。前台自动同步、数据库记录批量操作、编辑排版稳定与桌面常驻明确列入测试构建；不计入正式版安装包。五种数据库视图、22 种本地属性、内容块、页面链接、多工作区 Git 同步、导入与结构化备份均依据 README 与产品文档。

网站的三主题与三语言仅适用于官网，不代表客户端已加入英语或这些主题。未签名 iOS 文件不能直接安装；首次安装和签名边界在下载区域明确说明。

下载使用 GitHub Releases 的 `latest/download/固定资产名`，已与真实正式版资产逐项核对。正式版本标签文字为发布时的明确快照，不在每次访问时请求 GitHub API。发布新正式版时，同时更新三语言字典的 `download.stable`、HTML 默认文案和正式版本链接；若测试能力转正，也要同步更新测试说明与常见问题，不只修改版本号。

三张截图分别来自 `docs/界面/多选与拖拽分栏桌面.png`、`docs/界面/命名视图组合筛选.png`、`docs/界面/手机分栏堆叠与批量操作.png`，仅转换为 WebP，未伪造产品界面。切换网站语言不会翻译截图内的真实客户端中文。

## 交互、隐私与降级

语言与主题、暂停设置保存在访客浏览器的 `qingjian-site-*` 本地偏好中，存储被禁用时仅在当前页面生效。默认简体中文、纸白主题，不请求远程字体、CDN、统计或第三方接口；访客点击文档或下载时才前往 GitHub。托管服务自身按其规则处理访问日志。

Three.js 与正文独立加载；没有 WebGL 或图形上下文丢失时保留静态纸页，阅读和下载不受影响。页面离屏或标签隐藏时停止动画；减少动态偏好默认暂停，可手动开启，动效暂停可以单独记住。完全关闭 JavaScript 时仍可阅读简体中文介绍、展开原生常见问题和使用下载链接。

## 验证与发布

```bash
node scripts/check-website.mjs
node tests/e2e/website.mjs
node scripts/check-docs.mjs
git diff --check
```

浏览器依赖沿用项目 Playwright；首次在 Linux 安装 `npx playwright install --with-deps chromium`，macOS 默认使用 Chrome。测试从 `/qingjian/` 子路径加载，覆盖实际 WebGL 画布、主题及语言切换和刷新、截图分类与键盘操作、图片放大、五种屏宽、移动导航、减少动态偏好、WebGL 和存储不可用、无脚本阅读。截图和验证报告在 `test-results/website/`，不提交生成文件。

`main` 中官网目录、官网检查、官网浏览器回归或 Pages 工作流有变更时自动发布，也支持手动运行。工作流先执行检查与浏览器回归，再使用官方 `configure-pages`、`upload-pages-artifact`、`deploy-pages` 发布 `website/`。合并请求只验证，不发布；无需部署密钥，不修改客户端版本与正式发布标签。

仓库 Pages 来源使用 GitHub Actions。排查时先检查[官网工作流](https://github.com/a602017206/qingjian/actions/workflows/pages.yml)与 Pages 环境结果，再访问公开 URL 检查页面和资源；不能仅凭推送成功认定网站已经上线。
