## 15:27 苹果桌面包增加磁盘映像

按要求在原有压缩包之外增加苹果桌面磁盘映像产物，并只改动流水线与打包脚本，不做本机端到端安装验证。

- `scripts/package-macos.py`：新增 `DISK_NAME = '轻笺-苹果桌面.dmg'`，新增 `disk_layout` 与 `write_disk_image`，用 `hdiutil create` 生成只读 UDZO 映像并挂载回读，逐项核对应用文件、说明文件、权限与符号链接，映像内放置「Applications」替身，便于双击挂载后拖拽安装；磁盘映像另出 `.sha256` 摘要。`package_app` 增加 `disk` 开关，`main` 增加 `--no-dmg`，默认同时产出压缩包与磁盘映像。
- `scripts/release.mjs`：发布产物清单由八项增为十项，新增 `qingjian-macos-arm64.dmg` 与 `qingjian-macos-x64.dmg`；整理步骤按平台同时收集 `.zip` 与 `.dmg`。
- `.github/workflows/desktop.yml`：苹果平台整理产物步骤改为对整个产物目录执行收集，压缩包与磁盘映像一起进入发布产物。
- `ui/web/updates.mjs`：苹果两种架构的更新下载优先提供磁盘映像，压缩包作为备选。
- `website/index.html` 与 `website/i18n.mjs`：苹果下载卡新增磁盘映像入口，中文、繁体与英文文案统一走字典。
- `README.md`：苹果桌面下载行补充磁盘映像链接，首次打开说明改为「磁盘映像挂载后拖入应用程序，压缩包需先解压」。
- `docs/构建与发布.md`：补充磁盘映像产物说明与 `--no-dmg` 用法，产物数量表述由八种改为十种。

已通过 `python3 tests/package_macos.py`（7 项）、`node --test tests/updates.test.mjs tests/release.test.mjs`（8 项）与 `node scripts/check-website.mjs`；本机沙箱内 `hdiutil create` 因 `Operation not permitted` 无法执行，沙箱外同一命令可正常生成磁盘映像，说明打包逻辑本身可用。
