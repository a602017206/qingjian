## 三、已经实现的主要功能

### 页面、目录与空间管理

- 多个独立工作区，每个工作区可绑定自己的远程仓库。
- 父子页面树与目录折叠、侧边栏收起、全宽和阅读宽度、页面目录及反向链接。
- 页面标题、图标、封面、标签、收藏、复制、移动、锁定；页面与页面链接的右键菜单，包含搜索操作、颜色、图标、重命名、复制链接等入口。
- 数据库记录右侧预览和独立子页面；已有独立窗口等打开入口。
- 页面多选批量移入回收站、恢复、所选或全部永久清理；删除和勾选保持列表滚动位置。
- 永久清理核对共享附件引用，不自动改写版本历史。工作区支持本机移除、恢复和明确永久删除，不删除远程仓库及其他设备数据。
- 磁盘占用按 `B/KB/MB/GB` 显示，区分笔记、附件和版本历史。

### 内容块与编辑器

- 文本、六级标题、有序和无序列表、待办、引用、提示框、代码、分隔线、折叠列表、简易表格、图片与附件。
- 文档粘贴识别标题、列表、待办、代码围栏、链接、表格及常用行内格式。复杂内容保留原文，提供完整预览与源码编辑，不强行有损转换。
- 就地斜线搜索菜单，多层嵌套、折叠、子树拖动、复制删除、上下移动、键盘缩进及退出缩进、撤销重做。
- 内容块多选，支持修饰键、连续扩选、框选和手机勾选；批量类型、文字色、背景色、待办状态、复制、删除和缩进操作。
- 拖拽分栏，最多六列，可调列宽、均分和恢复单栏；手机按列上下堆叠。
- 最新修复使普通多行块在预览和编辑时保留行首空格、制表符、空行和末尾换行；按实际内容测高，格式工具浮动，切换只保留一个编辑框，保持相邻块和滚动位置。
- **仍不是完整所见即所得编辑器。** 编辑时部分格式显示文档符号，复杂源码与渲染排版仍可能不同，不能承诺全面复刻参考产品。

### 数据库、记录与属性

- 区分简易表格与属性数据库；支持表格、看板、列表、图库、日历五种视图，看板拖卡更新状态。
- 命名视图，独立保存布局、可见属性、组合筛选、多层排序和分组。筛选最多三层、六十四个条件节点，排序最多八层；设备记住当前视图，快速搜索不写入共享视图配置。
- 二十二种本地属性：文本、数字、选择、多选、状态、日期、人员、文件和媒体、复选框、网址、电子邮件、电话、公式、关联关系、汇总、创建时间、创建者、编辑时间、编辑者、按钮、位置、编号。
- 状态圆点和彩色标签；属性菜单支持重命名、配置、显示隐藏、复制删除及布局。选项可搜索，弹层跟随操作位置，手机提供底部操作界面。
- 导入记录的独立子页面显示父数据库结构化属性，点击修改会写回父数据库对应行，不再只作为正文文本。
- 人员是本地名单，位置为手动地址或经纬度；媒体支持本地附件或链接；系统元信息和编号只读，编号不复用。
- 基础受控公式、安全求值、同工作区单向关联和汇总、受控赋值按钮，计算失败明确提示。
- 最新测试功能包含五视图记录多选、连续扩选、当前可见范围全选、批量修改一个可写属性、集合替换追加移除及明确清空、所选导出、复制和移除撤销。选择不会重建行输入或跳动滚动位置。
- 批量提交前核对上下文和快照，失败保留草稿；切换页面、工作区、视图、筛选、排序或日历月份清空选择。
- **限制：**含独立子页面的记录暂不支持整批复制；批量移除只移除数据库行，先存本地版本，保留独立子页正文和附件。标题、系统、计算属性不可批改，媒体和位置逐项编辑。完整公式兼容、双向关联、关联数据库视图、日期区间和自动化未完成。

### 导入、导出与迁移

- 支持参考产品导出的压缩包，读取其中表格、标记文本和网页文件，也支持独立文件与轻笺结构化备份。
- 恢复父子层级、数据库与记录子页对应关系，核对显示表格与全字段表格，避免所有子页面平铺。
- 网页导入识别显式属性类型、状态与选项颜色、图标及明确的页面链接样式；无结构定义的表格按明确字段和内容推断，给出报告，不假造原始配置。
- 提供旧导入整理入口，歧义不会直接猜测覆盖。附件迁移和结构化恢复会重映射页面及附件引用。
- 支持文本、表格、附件和完整结构化压缩备份导出。完整恢复优先使用结构化备份；独立文本不能保留所有分栏和数据库配置。
- 源导出本身没有的权限、评论、作者、公式或关系逻辑无法凭空恢复；之前丢失的样式也不能在缺少原文件时准确还原。

### 本地保存、同步、认证与冲突

- 本机文件优先、自动保存、版本核对、失败重试、草稿恢复和页面历史。
- 内置版本同步能力，电脑和手机均无需安装 `Git`，用户无需执行命令。
- 支持 `GitHub`、`GitLab`、`Gitee` 及兼容加密网页地址的仓库，配置实际分支；多工作区认证独立。
- 原生端通过系统安全凭据服务记住认证；安卓使用系统密钥库加密私有存储，苹果使用钥匙串。安全存储失败明确报错，不降级为明文；浏览器开发服务仅会话认证。
- 国内仓库要求真实用户名和有仓库权限的私人令牌，错误信息不再显示无定义值，也不泄露密钥。
- 首次绑定已有独立历史，可选以本机、远程或合并处理，操作前保留双方恢复点，不强推。
- 不同笔记自动合并；同一笔记或数据库双方修改时，应用内核对摘要并选择整篇版本，不承诺逐块或逐单元格自动合并。过时选择拒绝执行。
- 恢复点可恢复为独立工作区，不覆盖当前数据。
- **自动同步已实现，尚未正式发布：**启动、回到前台或获得焦点、编辑停止约四秒、前台约两分钟补查、网络恢复重试，各工作区可关闭。
- 等待网络时可继续编辑；返回时核对最新草稿，双方修改则暂停并选择保留本机、保留同步版本或另存副本，没有默认覆盖。完整草稿恢复点保存正文、数据库和附件。
- 已处理跨工作区旧回包、冲突状态隔离、附件删除与同名替换等保护。后台、休眠或进程被系统结束后不保证继续同步。

### 桌面常驻、移动适配、构建与更新

- 最新桌面菜单栏或托盘提供显示主窗口、快速搜索、新建和退出，也接入系统原生笔记菜单。
- 关闭主窗口先保存再隐藏；独立窗口保存后关闭。退出等待全部窗口保存，未提交弹层、保存失败或草稿冲突会阻止退出并保留输入。无托盘环境最后窗口可正常退出。
- 快速搜索和新建快捷键为应用内快捷键，不是全局系统快捷键；没有默认开机自启。
- 手机数据库、属性编辑、内容块操作支持触控入口、底部弹层、窄屏和键盘避让；桌面手机共享代码。
- 支持简繁中文、浅色深色及跟随系统、字体设置。
- 云端可构建苹果桌面两架构、微软桌面、开源桌面、安卓六十四位、苹果移动端模拟器及未签名真机包。
- 苹果桌面临时签名和完整性校验、包内中文首次打开说明已实现；这不等于付费开发者签名及公证。
- 安卓固定签名、安卓十六冷启动和十六千字节页适配验证已接入。不要重复手动初始化 `ndk-context`：当前 `Tao 0.37.1` 已自行初始化，重复初始化曾造成启动闪退。
- 检查新正式版本，按当前系统和架构选择下载安装包；失败不假称最新版，不静默安装。
- 苹果移动端有免费账号自行签名说明，但尚未完成真机全功能验收，不能说存在无需签名、永久免费的公开安装方案。

## 六、新对话启动时的操作

先读取 `AGENTS.md`、`README.md`、本交接文件，以及 `docs/使用指南.md`、`docs/表格与高级数据库指南.md`、`docs/架构与数据格式.md` 和 `docs/验证报告.md` 最新部分，检查 `git status` 与最近提交。只补读与当前任务相关的日记，不必从头重做历史工作。

重点代码入口：

- `ui/web/app.mjs`、`editor.mjs`、`markdown.mjs`：界面、保存和编辑。
- `ui/web/block-*`、`column-layout.mjs`：内容树、多选和分栏。
- `ui/web/database*.mjs`、`property-*.mjs`：视图、属性和批量操作。
- `ui/web/auto-sync.mjs`、`auto-sync-ui.mjs`：自动同步与草稿保护。
- `ui/web/desktop-actions.mjs`、`api.mjs`、`i18n.mjs`、`style.css`：原生桥接、字典和样式。
- `crates/notebook/src/`：共享存储、导入与同步核心。
- `src-tauri/src/desktop.rs`、`desktop_actions.rs`、`credentials.rs`：桌面菜单、退出和安全认证。
- `.github/workflows/`、`scripts/package-macos.py`、`scripts/check-android.py`：构建与校验。

按照改动范围运行验证，不因换对话重复所有构建。常用命令：

```sh
npm test
npm run check
npm run build
npm run release:check
node scripts/check-docs.mjs
cargo test --locked -p notebook-core
cargo test --locked -p qingjian --lib
```

相关界面回归：

```sh
npm run test:e2e:editor-stability
npm run test:e2e:desktop-window
npm run test:e2e:database-batch
npm run test:e2e:auto-sync
```
