# 使用指南

## 开始记录

第一次打开轻笺会创建「个人笔记」工作区，并提供几篇示例。点击「新建页面」，输入标题，然后点击正文开始写作。修改约在输入停止后自动保存；也可使用保存快捷键立即保存。

正文支持 Markdown 的加粗、斜体、删除线、代码与链接符号。编辑状态保留符号，退出内容块或切换到预览后显示格式。输入 `/` 选择内容块；输入完成后按回车创建下一块，换行使用换行组合键。代码块中的回车直接换行。

桌面可以拖动块左边的手柄排序。手机点击块左侧的加号打开菜单，再选择上移、下移或删除。页面标题中的图标与封面可以更换，封面目前提供内置配色。

## 整理页面

使用页面左侧的加号创建子页面，也可以在「所属页面」中移动现有页面。页面层级不能形成循环。收藏页面会显示在导航收藏区，标签用于工作台筛选。

「更多操作」提供复制、宽版、锁定、Markdown 导出和移入回收站。删除父页面时子页面一起进入回收站；恢复时保留内容。锁定只是防误编辑，不是加密或访问权限。

页面名称链接的写法为 `[[页面名称]]`。导入或程序生成的稳定链接使用页面标识。右侧目录从标题块生成；关联信息显示哪些页面引用当前页面。手机和窄窗口会隐藏右侧辅助栏。

## 表格与数据库

普通页面可以从内容菜单插入「简易表格」，直接编辑单元格和增删行列。需要筛选、排序、计算或关联时，选择工作台或导航里的「新建数据库」。

数据库提供表格、看板、列表、图库和日历视图，支持多选、基础公式、跨数据库关联、汇总以及记录详情。模板中的「高级数据库示例」提供可直接体验的计算数据。

详细步骤、公式语法和兼容边界见 [表格与高级数据库指南](表格与高级数据库指南.md)。完整的 Notion 公式、双向关联、命名视图与多人权限尚未实现。

## 配置多个仓库

点击导航上方的工作区名称，选择「添加工作区」。填写中文名称、远程仓库 HTTPS 地址与分支。

- 创建新仓库：创建本地独立工作区，可推送到空的远程仓库。
- 克隆已有仓库：读取所选远程分支中的轻笺笔记文件。
- 留空远程地址：仅在本地保存，之后可到设置补充地址。

已有工作区不直接切换分支。需要使用其他分支时，创建工作区并克隆目标分支。每个工作区的配置、笔记与 Git 历史彼此独立。

私有仓库在工作区设置中填写用户名与访问令牌。GitHub 令牌需要目标仓库内容的读取和写入权限；GitLab 令牌需要仓库读取和写入权限。令牌只保存在本次会话内，退出后需重新设置。不要把令牌放进仓库地址。

点击「保存版本」创建本地版本。点击「同步」提交当前修改并与远程交换内容。远程没有配置时仍可保存本地版本。同步期间暂时保护编辑内容，完成后恢复编辑。

## 分叉与失败

如果两台设备分别修改后产生分叉，应用会停止同步并保留本地提交。可以在桌面的笔记仓库中用 Git 手动合并，再返回应用同步；或者新建工作区克隆远程版本，比较并迁移需要保留的内容。

应用不会强制推送，也不会为了同步成功而重置本地历史。认证或网络失败不影响已有本地版本。保存失败时当前输入与恢复草稿仍保留，应先重试保存，再离开页面。

## 导入 Notion

在 Notion 的导出菜单中选择 Markdown 与 CSV 或 HTML，勾选包含子页面，下载导出压缩包。轻笺里点击「导入笔记」，选择文件并查看报告。

安卓文件提供器可能不返回文件名。压缩包可按内容自动识别；直接选择文本、表格或网页文件时，可以在导入窗口指定对应格式。

首版支持中文页面、基础内容块、子页面、页面间链接、附件和 CSV 数据库记录。评论、权限、公式逻辑、关联汇总以及复杂布局不能从导出文件完整还原。导入后应核对重要笔记和数据库，并保留原导出包。

大于一百二十八兆字节的导出内容请拆分导入。导入不会覆盖现有笔记；重复导入会创建新的页面，但相同附件尽量复用。

## 导出与恢复

设置中的「导出笔记」生成完整压缩备份，包含结构化页面、Markdown、数据库表格及附件。恢复时通过「导入笔记」选择这份压缩包。回收站页面不包含在导出备份中，但仍保留在原工作区。

五个平台使用系统保存对话框选择导出位置。单页 Markdown 导出适合阅读和分享，不包含完整数据库及附件副本。需要保留所有历史时，以 Git 仓库克隆为准。

## 外观和磁盘

设置里可以切换浅色、深色、跟随系统主题，以及简体和繁体中文。语言设置影响界面，已有正文不会自动翻译。

磁盘统计显示当前工作区实际文件大小，分为笔记、附件和 Git 历史。它不包含应用安装体积，也不包含系统网页内核的共享缓存。大量附件和长期版本历史仍会增加磁盘占用；首版不自动压缩历史或永久清理附件。

## 导入后状态、颜色与页面空间

影视表格等旧数据如仍显示普通文字，可以打开数据库点击「整理导入数据」，核对字段与子页面归属建议后应用。状态支持圆点和颜色，单选、多选支持彩色标签，颜色可在属性设置中修改。纯文本表格中的原有颜色无法精确恢复，导入报告会注明类型推断。

正文默认全宽，顶部可切换阅读宽度和页面信息；菜单按钮可以收起或展开桌面侧栏。工作台默认显示顶层页面，目录箭头可折叠子页面，搜索仍覆盖全部层级。具体说明见 [表格与高级数据库指南](表格与高级数据库指南.md)。

## 页面右键菜单

桌面在侧栏页面、收藏条目、工作台列表或卡片上点击右键，可以直接打开编辑、重命名、添加或取消收藏、创建副本、移动到其他父页面、移至回收站。页面旁的省略号也能打开同一个菜单，手机不需要右键操作。

移动位置会排除自身和子孙页面，避免形成循环；锁定的笔记不能通过菜单重命名或移动。移至回收站仍可恢复，删除父页面沿用原有的子页面处理规则。菜单操作前会保存当前草稿，操作期间保护编辑和工作区切换，避免把背景页面的操作写到另一工作区。

键盘聚焦页面后可使用菜单组合键打开快捷菜单，方向键切换选项，回车执行，退出键关闭并回到原页面入口。点击菜单外或滚动也会关闭菜单。

```text
Shift+F10
ArrowUp ArrowDown Home End
Enter Escape
```

## 批量删除错误导入

侧栏「我的页面」旁的勾选按钮、工作台列表工具栏的「批量管理」均可进入批量模式。勾选需要处理的页面后，点击「批量移至回收站」，检查数量和页面名称再确认。所选父页面的子页面会一起处理，重复勾选不会重复计数，已在回收站的页面不会被重新修改删除时间。

「选择全部页面」包含当前工作区收起的子页面；工作台的「选择当前列表」只勾选当前筛选列表，适合先搜索再批量处理。「取消选择」清空勾选，「退出批量」返回正常列表。切换或新建工作区时选择会清空，不会把同一仓库另一份工作区的页面标识当作本次选择。

删除和勾选时侧栏尽量保留原来的可见页面及位置，当前主列表也保留滚动位置；打开另一篇笔记时仍从新页面顶部开始。列表已经缩短到不足原滚动高度时，会停在可用的最接近位置。

## 永久删除与清空回收站

回收站提供单项「永久删除」、勾选后的「永久删除所选」和「清空回收站」。先展示将删除的页面数量、可清理的相关附件数量及预计释放空间，再由你确认。取消预览不会删除文件；永久删除后不能通过回收站恢复。

清理前会重新核对页面版本和附件清单。仍在使用的页面不能被永久删除；剩余页面，包括没有被选中的回收站页面，共享的附件会保留。只清理已删除页面所引用且没有其他页面引用的相关附件，不擅自清理未知来源的文件。清理结束显示实际移除文件大小，中途失败会显示已释放大小及错误。

本地 Git 历史与远程仓库仍可能保留旧内容，本次不会改写历史或强制推送，所以不会将历史占用伪装成已经释放。恢复仍保留的历史页面时，会尝试从对应提交补回其历史附件；原提交缺失附件时会明确报告。磁盘统计在清理后刷新，笔记文件、附件与版本历史分别统计。


## 表格父页面与无标识子目录

父表格文件名带导出标识、子目录只有页面名称的压缩包，现在会还原父子层级。普通表格和完整字段表格经记录核对属于同一数据库时，合并为一个父页面并保留全部字段。点击父页面左侧箭头展开子页面，再次点击收起；表格记录能打开唯一对应的原始子页面。

升级不会自动改动旧的平铺页面。重新导入前可以新建空工作区验证，或先把旧错误导入批量移入回收站；同名页面和正文不会被静默合并或覆盖。

## 连续勾选位置保持

单项勾选、取消、全选和取消选择只更新复选框、数量与操作按钮，侧栏和工作台中的同一页面同步显示，不重建列表，也不触发滚动动画。键盘选择会保留当前控件焦点。需要整体刷新界面时，旧位置采用即时恢复，避免短暂跳到顶部再滑回。


## 网页格式数据库导入

选择网页格式导出的完整压缩包，并保留父网页、配套表格、子目录和附件的相对位置。导入器会读取网页里的状态、单选、多选、日期、数字定义及选项原色，而非全部当作文字。父数据库的记录通过网页链接和页面标识关联对应子页面；同名页面继续独立保存。

配套完整字段表格与父网页只有在源标识和记录内容可核对时才归并；可见字段按网页次序排列，额外字段和记录仍保留。字段原值、网页属性和原始来源信息保留在数据中。遇到标识冲突、同名记录无法区分或原值不一致时，导入报告会说明处理方式，不会强行覆盖或猜测关联。

表格单元格中的附件、自定义链接和图片，按记录名称及字段名称另外保留到父页面正文，可继续查看或下载；子页面属性中的链接也保留。远程封面和图片只保留地址，不自动下载。复杂网页布局、多张表格的组合、导出未包含的视图配置和公式逻辑不能完整恢复。

已错误导入的页面不会随升级自动重写。建议先用空工作区重新导入验证，再按「批量删除错误导入」处理旧页面，避免两次导入同时展示。


## 容量显示单位

磁盘统计、侧栏容量及清理空间统一显示为 B、KB、MB、GB，按一千零二十四进位；导入限制也采用相同单位缩写。


## 数据库子页面属性

从数据库打开已关联子页面，标题下方会显示结构化属性区：字段图标、状态圆点、单选及多选原色、日期和数字控件。空值显示「空白」。页面自身的标签和所属页面放在可展开的「页面信息」中，正文单独显示。

子页面的属性值来自父数据库对应记录。修改后自动保存到父数据库；在父表格修改后重新打开子页也会显示新值。父数据库或子页面锁定时，属性不能编辑。正文仍保存到子页面，不会因属性修改而覆盖。

已有导入笔记只要父子记录关联正确，升级后即可显示属性区，无需为本次界面修复重新导入。原属性文字快照完整核对一致时不再重复显示，磁盘原文仍保留；被修改或删减的段落仍作为正文显示。无法唯一关联的页面继续保留正文，不猜测对应记录。

保存失败时属性草稿留在当前界面和本机恢复缓存，可以点击重试。刷新后再打开子页面会尝试恢复草稿；如果父数据库版本已经改变，会保留独立的属性草稿恢复副本，不覆盖最新数据。恢复过程中暂时保护编辑，切换工作区前等待当前属性及正文保存完成。


## 单击属性名称与字段设置

数据库类型已经可以识别：网页导出提供显式字段定义，纯文本表格只能根据列名和内容推断。属性名称和属性值分别操作：单击右侧的值修改当前记录，单击左侧属性名称打开属性操作菜单。

属性菜单支持重命名、编辑类型和选项颜色、创建属性副本、删除属性、属性可见性和自定义布局。属性区底部可新增字段。字段定义属于父数据库，所以名称、类型、选项及删除会应用到它的所有记录；删除前会确认影响。副本复制字段定义和所有记录的当前值，原字段继续保留。

可见性支持始终显示、为空时隐藏、始终隐藏。隐藏不会删除字段和值，可以在底部「自定义布局」重新显示；布局中也能上移和下移属性，规则适用于该数据库的各个子页面。空数字和零分别处理，重命名不会改变已经确定的显示位置。

父数据库或子页面锁定、预览和保存保护期间不允许修改字段。弹窗核对打开时的工作区及父数据库，导航从开始即保护编辑，避免把旧字段设置写到另一数据库。字段设置与值编辑沿用同一份父数据库草稿、自动保存、错误重试及恢复机制。

## 人员、媒体和自动属性

新增或编辑属性时，点击属性类型按钮，输入中文名称可以筛选类型。二十二种类型及实际行为见《表格与高级数据库指南》。人员名单在字段设置中维护；媒体属性点击值可上传文件、添加网页链接、下载或移除；位置属性点击值可修改地址及成对经纬度。

创建和编辑信息由应用记录，导入缺少的原作者显示未知；缺少原始时间时以导入时的页面时间初始化。编号支持前缀且不会复用已删除记录的号码。按钮在字段设置中指定当前记录的目标和值，执行前需要确认。被按钮使用的字段须先调整按钮配置，才能删除或改为不可写类型。

本轮先完成本地属性，智能总结和翻译将在后续配置模型接口后接入。
