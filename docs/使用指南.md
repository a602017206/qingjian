# 使用指南

## 开始记录

第一次打开轻笺会创建「个人笔记」工作区，并提供几篇示例。点击「新建页面」，输入标题，然后点击正文开始写作。修改约在输入停止后自动保存；也可使用保存快捷键立即保存。

正文支持 Markdown 的加粗、斜体、删除线、代码与链接符号。编辑状态保留符号，退出内容块或切换到预览后显示格式。输入 `/` 选择内容块；输入完成后按回车创建下一块，换行使用换行组合键。代码块中的回车直接换行。

桌面可以拖动块左边的手柄排序。手机点击块左侧的加号打开菜单，再选择上移、下移或删除。页面标题中的图标与封面可以更换，封面目前提供内置配色。

## 整理页面

使用页面左侧的加号创建子页面，也可以在「所属页面」中移动现有页面。页面层级不能形成循环。收藏页面会显示在导航收藏区，标签用于工作台筛选。

「更多操作」提供复制、宽版、锁定、Markdown 导出和移入回收站。删除父页面时子页面一起进入回收站；恢复时保留内容。锁定只是防误编辑，不是加密或访问权限。

页面名称链接的写法为 `[[页面名称]]`。导入或程序生成的稳定链接使用页面标识。右侧目录从标题块生成；关联信息显示哪些页面引用当前页面。手机和窄窗口会隐藏右侧辅助栏。

## 表格与数据库

普通页面可以从内容菜单插入「简易表格」，直接编辑单元格和增删行列。需要筛选、排序、计算或关联时，选择工作台或导航里的「新建数据库」。

数据库提供表格、看板、列表、图库和日历视图，支持多选、基础公式、跨数据库关联、汇总以及记录详情。模板中的「高级数据库示例」提供可直接体验的计算数据。

详细步骤、公式语法和兼容边界见 [表格与高级数据库指南](表格与高级数据库指南.md)。完整公式兼容、双向关联、日期区间与多人权限尚未实现。

## 配置多个仓库

点击导航上方的工作区名称，选择「添加工作区」。填写中文名称、远程仓库 HTTPS 地址与分支。

- 创建新仓库：创建本地独立工作区，可推送到空的远程仓库。
- 克隆已有仓库：读取所选远程分支中的轻笺笔记文件。
- 留空远程地址：仅在本地保存，之后可到设置补充地址。

已有工作区不直接切换分支。需要使用其他分支时，创建工作区并克隆目标分支。每个工作区的配置、笔记与 Git 历史彼此独立。

Gitee、GitHub 和 GitLab 均可使用加密网页协议连接。需要认证时在工作区设置中填写用户名与访问令牌。GitHub 令牌需要目标仓库内容的读取和写入权限；GitLab 令牌需要仓库读取和写入权限。原生应用可勾选“记住此工作区的认证”，退出后从本机系统安全凭据库自动读取；不勾选或使用浏览器服务时，仅本次运行有效。不要把令牌放进仓库地址。

点击「保存版本」创建本地版本。点击「同步」提交当前修改并与远程交换内容。远程没有配置时仍可保存本地版本。手动同步期间暂时保护编辑内容，完成后恢复编辑。自动同步的网络等待期间可以继续输入，返回后核对当前草稿再保存。

## 分叉与失败

两台设备修改不同笔记时自动合并；修改同一笔记时，在应用里核对双方摘要并选择保留的版本。覆盖前保留双方恢复点，详情见后文「同步冲突与工作区管理」。

应用不会强制推送，也不会为了同步成功而重置本地历史。认证或网络失败不影响已有本地版本。保存失败时当前输入与恢复草稿仍保留，应先重试保存，再离开页面。

## 导入 Notion

在 Notion 的导出菜单中选择 Markdown 与 CSV 或 HTML，勾选包含子页面，下载导出压缩包。轻笺里点击「导入笔记」，选择文件并查看报告。

安卓文件提供器可能不返回文件名。压缩包可按内容自动识别；直接选择文本、表格或网页文件时，可以在导入窗口指定对应格式。

首版支持中文页面、基础内容块、子页面、页面间链接、附件和 CSV 数据库记录。评论、权限、公式逻辑、关联汇总以及复杂布局不能从导出文件完整还原。导入后应核对重要笔记和数据库，并保留原导出包。

大于一百二十八兆字节的导出内容请拆分导入。导入不会覆盖现有笔记；重复导入会创建新的页面，但相同附件尽量复用。

## 导出与恢复

设置中的「导出笔记」生成完整压缩备份，包含结构化页面、Markdown、数据库表格及附件。恢复时通过「导入笔记」选择这份压缩包。回收站页面不包含在导出备份中，但仍保留在原工作区。

五个平台使用系统保存对话框选择导出位置。单页 Markdown 导出适合阅读和分享，不包含完整数据库及附件副本。需要保留所有历史时，以 Git 仓库克隆为准。

## 外观和磁盘

设置里可以切换浅色、深色、跟随系统主题，以及简体和繁体中文。语言设置影响界面，已有正文不会自动翻译。

磁盘统计显示当前工作区实际文件大小，分为笔记、附件和 Git 历史。它不包含应用安装体积，也不包含系统网页内核的共享缓存。大量附件和长期版本历史仍会增加磁盘占用；首版不自动压缩历史或永久清理附件。

## 导入后状态、颜色与页面空间

影视表格等旧数据如仍显示普通文字，可以打开数据库点击「整理导入数据」，核对字段与子页面归属建议后应用。状态支持圆点和颜色，单选、多选支持彩色标签，颜色可在属性设置中修改。纯文本表格中的原有颜色无法精确恢复，导入报告会注明类型推断。

正文默认全宽，顶部可切换阅读宽度和页面信息；菜单按钮可以收起或展开桌面侧栏。工作台默认显示顶层页面，目录箭头可折叠子页面，搜索仍覆盖全部层级。具体说明见 [表格与高级数据库指南](表格与高级数据库指南.md)。

## 页面右键菜单

桌面在侧栏页面、收藏条目、工作台列表或卡片上点击右键，可以直接打开编辑、重命名、添加或取消收藏、创建副本、移动到其他父页面、移至回收站。页面旁的省略号也能打开同一个菜单，手机不需要右键操作。

移动位置会排除自身和子孙页面，避免形成循环；锁定的笔记不能通过菜单重命名或移动。移至回收站仍可恢复，删除父页面沿用原有的子页面处理规则。菜单操作前会保存当前草稿，操作期间保护编辑和工作区切换，避免把背景页面的操作写到另一工作区。

键盘聚焦页面后可使用菜单组合键打开快捷菜单，方向键切换选项，回车执行，退出键关闭并回到原页面入口。点击菜单外或滚动也会关闭菜单。

```text
Shift+F10
ArrowUp ArrowDown Home End
Enter Escape
```

## 批量删除错误导入

侧栏「我的页面」旁的勾选按钮、工作台列表工具栏的「批量管理」均可进入批量模式。勾选需要处理的页面后，点击「批量移至回收站」，检查数量和页面名称再确认。所选父页面的子页面会一起处理，重复勾选不会重复计数，已在回收站的页面不会被重新修改删除时间。

「选择全部页面」包含当前工作区收起的子页面；工作台的「选择当前列表」只勾选当前筛选列表，适合先搜索再批量处理。「取消选择」清空勾选，「退出批量」返回正常列表。切换或新建工作区时选择会清空，不会把同一仓库另一份工作区的页面标识当作本次选择。

删除和勾选时侧栏尽量保留原来的可见页面及位置，当前主列表也保留滚动位置；打开另一篇笔记时仍从新页面顶部开始。列表已经缩短到不足原滚动高度时，会停在可用的最接近位置。

## 永久删除与清空回收站

回收站提供单项「永久删除」、勾选后的「永久删除所选」和「清空回收站」。先展示将删除的页面数量、可清理的相关附件数量及预计释放空间，再由你确认。取消预览不会删除文件；永久删除后不能通过回收站恢复。

清理前会重新核对页面版本和附件清单。仍在使用的页面不能被永久删除；剩余页面，包括没有被选中的回收站页面，共享的附件会保留。只清理已删除页面所引用且没有其他页面引用的相关附件，不擅自清理未知来源的文件。清理结束显示实际移除文件大小，中途失败会显示已释放大小及错误。

本地 Git 历史与远程仓库仍可能保留旧内容，本次不会改写历史或强制推送，所以不会将历史占用伪装成已经释放。恢复仍保留的历史页面时，会尝试从对应提交补回其历史附件；原提交缺失附件时会明确报告。磁盘统计在清理后刷新，笔记文件、附件与版本历史分别统计。


## 表格父页面与无标识子目录

父表格文件名带导出标识、子目录只有页面名称的压缩包，现在会还原父子层级。普通表格和完整字段表格经记录核对属于同一数据库时，合并为一个父页面并保留全部字段。点击父页面左侧箭头展开子页面，再次点击收起；表格记录能打开唯一对应的原始子页面。

升级不会自动改动旧的平铺页面。重新导入前可以新建空工作区验证，或先把旧错误导入批量移入回收站；同名页面和正文不会被静默合并或覆盖。

## 连续勾选位置保持

单项勾选、取消、全选和取消选择只更新复选框、数量与操作按钮，侧栏和工作台中的同一页面同步显示，不重建列表，也不触发滚动动画。键盘选择会保留当前控件焦点。需要整体刷新界面时，旧位置采用即时恢复，避免短暂跳到顶部再滑回。


## 网页格式数据库导入

选择网页格式导出的完整压缩包，并保留父网页、配套表格、子目录和附件的相对位置。导入器会读取网页里的状态、单选、多选、日期、数字定义及选项原色，而非全部当作文字。父数据库的记录通过网页链接和页面标识关联对应子页面；同名页面继续独立保存。

配套完整字段表格与父网页只有在源标识和记录内容可核对时才归并；可见字段按网页次序排列，额外字段和记录仍保留。字段原值、网页属性和原始来源信息保留在数据中。遇到标识冲突、同名记录无法区分或原值不一致时，导入报告会说明处理方式，不会强行覆盖或猜测关联。

表格单元格中的附件、自定义链接和图片，按记录名称及字段名称另外保留到父页面正文，可继续查看或下载；子页面属性中的链接也保留。远程封面和图片只保留地址，不自动下载。复杂网页布局、多张表格的组合、导出未包含的视图配置和公式逻辑不能完整恢复。

已错误导入的页面不会随升级自动重写。建议先用空工作区重新导入验证，再按「批量删除错误导入」处理旧页面，避免两次导入同时展示。


## 容量显示单位

磁盘统计、侧栏容量及清理空间统一显示为 B、KB、MB、GB，按一千零二十四进位；导入限制也采用相同单位缩写。


## 数据库子页面属性

从数据库打开已关联子页面，标题下方会显示结构化属性区：字段图标、状态圆点、单选及多选原色、日期和数字控件。空值显示「空白」。页面自身的标签和所属页面放在可展开的「页面信息」中，正文单独显示。

子页面的属性值来自父数据库对应记录。修改后自动保存到父数据库；在父表格修改后重新打开子页也会显示新值。父数据库或子页面锁定时，属性不能编辑。正文仍保存到子页面，不会因属性修改而覆盖。

已有导入笔记只要父子记录关联正确，升级后即可显示属性区，无需为本次界面修复重新导入。原属性文字快照完整核对一致时不再重复显示，磁盘原文仍保留；被修改或删减的段落仍作为正文显示。无法唯一关联的页面继续保留正文，不猜测对应记录。

保存失败时属性草稿留在当前界面和本机恢复缓存，可以点击重试。刷新后再打开子页面会尝试恢复草稿；如果父数据库版本已经改变，会保留独立的属性草稿恢复副本，不覆盖最新数据。恢复过程中暂时保护编辑，切换工作区前等待当前属性及正文保存完成。


## 单击属性名称与字段设置

数据库类型已经可以识别：网页导出提供显式字段定义，纯文本表格只能根据列名和内容推断。属性名称和属性值分别操作：单击右侧的值修改当前记录，单击左侧属性名称打开属性操作菜单。

属性菜单支持重命名、编辑类型和选项颜色、创建属性副本、删除属性、属性可见性和自定义布局。属性区底部可新增字段。字段定义属于父数据库，所以名称、类型、选项及删除会应用到它的所有记录；删除前会确认影响。副本复制字段定义和所有记录的当前值，原字段继续保留。

可见性支持始终显示、为空时隐藏、始终隐藏。隐藏不会删除字段和值，可以在底部「自定义布局」重新显示；布局中也能上移和下移属性，规则适用于该数据库的各个子页面。空数字和零分别处理，重命名不会改变已经确定的显示位置。

父数据库或子页面锁定、预览和保存保护期间不允许修改字段。弹窗核对打开时的工作区及父数据库，导航从开始即保护编辑，避免把旧字段设置写到另一数据库。字段设置与值编辑沿用同一份父数据库草稿、自动保存、错误重试及恢复机制。

## 人员、媒体和自动属性

新增或编辑属性时，点击属性类型按钮，输入中文名称可以筛选类型。二十二种类型及实际行为见《表格与高级数据库指南》。人员名单在字段设置中维护；媒体属性点击值可上传文件、添加网页链接、下载或移除；位置属性点击值可修改地址及成对经纬度。

创建和编辑信息由应用记录，导入缺少的原作者显示未知；缺少原始时间时以导入时的页面时间初始化。编号支持前缀且不会复用已删除记录的号码。按钮在字段设置中指定当前记录的目标和值，执行前需要确认。被按钮使用的字段须先调整按钮配置，才能删除或改为不可写类型。

本轮先完成本地属性，智能总结和翻译将在后续配置模型接口后接入。

## 数据库记录侧边预览与就地属性编辑

数据库记录的打开按钮默认在右侧预览当前记录。左侧保留原页面、表格视图及滚动位置，可打开另一条记录；右侧独立滚动并编辑当前记录的属性和正文。顶部关闭按钮返回表格，「以整页打开」切换到完整页面。手机使用全宽记录面板，仍共用相同字段控件。

状态和选择属性点击彩色标签打开相邻搜索菜单，点击选项立即保存并关闭；多选、人员和关联支持连续勾选，修改即时自动保存，点击外部或「完成」关闭。输入未存在的名称可直接创建本地选项；关联仍选择真实目标数据库的已有记录。空值可使用「清空」。

字段定义、重命名、位置与媒体管理在操作附近显示表单，配置完成后点击保存。调整窗口大小会重新定位弹层，保留尚未提交的输入。删除和按钮执行继续展示确认，避免误操作。

没有独立子页面的本地数据库记录同样使用右侧面板，可编辑记录标题和正文，并共用字段顺序及可见性。关闭或切换记录前等待保存；失败时保留当前记录、草稿和重试入口。侧栏直接打开子页面仍使用完整页面。


## 子页面条目与页面操作

独立的页面链接显示为紧凑的整行条目，使用子页面当前标题与图标，名称带下划线。页面改名后条目自动显示新名称，原始链接标识不变。含其他文字的段落继续作为正文显示，不会被误转换。

桌面右键正文条目，或点击条目左侧的六点按钮，可以打开可搜索的页面菜单。侧栏省略号和页面右上角也使用同一套菜单。手机可点击六点按钮，菜单会限制在屏幕范围内，长颜色列表可滚动。

- 「转换成」提供页面链接、文本、三级标题、项目列表、编号列表、待办、引用和提示块。只改变当前条目的显示形式，子页面及其正文保留；转换后的条目可再用六点菜单恢复页面链接。
- 「颜色」分别设置文字色与背景色，提供默认及九种颜色。正文条目颜色只影响当前条目；侧栏页面菜单设置的页面颜色用于标题及没有单独设置颜色的条目。
- 「编辑图标」提供表情选择、中文名称搜索、手动输入和本地图片上传。显式修改图标后，所有页面条目、侧栏和标题使用新的页面图标；原导入条目图标仍保留在源数据中。保存失败会保留原图标。
- 收藏、重命名、拷贝链接、创建副本、移动和回收沿用本地保存与回收站规则。副本复制当前页的正文与属性，子页面仍保持原有归属。
- 「在新选项卡中打开」使用应用内的页面选项卡；「在侧边预览中打开」保留父页面在背景中，关闭后返回原位置。按住选项键单击页面条目可打开侧边预览；按住系统命令键单击可打开新选项卡。
- 独立窗口是桌面功能，移动端该项不可用，可使用应用内选项卡或侧边预览。桌面「在新窗口中打开」打开独立原生窗口；浏览器预览打开独立浏览器窗口。定位链接包含本地工作区与页面标识，仅用于同一轻笺数据环境，不是公开分享地址。

普通页面的标签、所属页面折叠到「页面信息」中，编辑工具栏保持可访问，让标题与正文条目更接近原笔记的排版。「更多操作」仍可访问锁定、导出、版本历史等原有功能。

网页导入现在读取页头图标图片、表情及独立子页面条目的明确文字色和背景色。本地图标附件参与结构化备份，恢复时重新映射附件引用；同一页面重复出现时分别保留各条样式，混排正文不会消耗后续条目的样式。之前导入时已丢失的样式，需从原压缩包重新导入或通过菜单重新设置；导出本身没有包含的样式无法准确还原。智能操作按当前安排留到后续接入。

## 粘贴标记文档

在正文编辑区粘贴整篇 Markdown 文档，会自动识别标题、列表、引用、代码和表格；编辑时显示原始符号，退出编辑后显示排版。代码块内粘贴保持原文，不会把代码中的星号或链接改成格式。

| 内容 | 常用写法 |
| --- | --- |
| 一级到六级标题 | 行首一至六个 `#`，随后加空格 |
| 加粗、斜体、删除线 | `**加粗**`、`__加粗__`、`*斜体*`、`_斜体_`、`~~删除线~~` |
| 无序列表 | 行首 `- `、`* ` 或 `+ `；子项通过缩进表示 |
| 有序列表 | 行首 `1. ` 或 `1) `，保留起始序号 |
| 待办 | `- [ ] 未完成`、`- [x] 已完成` |
| 引用 | 行首 `> `；嵌套引用使用多个符号 |
| 行内代码 | 一对反引号；内容含反引号时可用更长的反引号包围 |
| 代码块 | 独立行三个反引号或波浪线，后接语言名称，末尾用对应围栏关闭 |
| 链接、图片、页面 | `[文字](地址)`、`![说明](地址)`、`[[页面名称]]` |
| 分隔线 | 独立行 `---`、`***` 或 `___` |
| 表格 | 竖线分列，表头下一行使用三个短横线分隔 |
| 转义 | 特殊符号前加反斜杠，例如 `\*普通星号\*` |

代码块示例：

````text
```bash
docker builder prune -f
```

这里继续写普通正文。
````

以上命令只作为笔记内容显示。远程图片先显示说明和地址，已导入的本地附件仍使用附件预览。

复杂的列表与引用交错、长起始编号、引用式链接等，在当前块模型无法完整表达时保留为整段源码并完整渲染，点击后可编辑原文。旧版本已经粘贴为长段落的文档也使用完整语法显示，不会自动重写笔记。数学公式、脚注及流程图尚未转换为专用内容块。


## 为数据库保存不同查看方式

点击数据库视图栏的加号，创建“全部记录”“观看中”“待处理”等命名视图。每个视图可保存不同布局、组合筛选、多层排序及显示属性。选择视图后，刷新和重新打开会在当前工作区恢复本机的选择。

筛选和排序入口位于视图栏右侧，数字显示已配置的规则数量。布局与属性设置可重命名、复制或删除视图；删除视图不会删除记录。详细示例和边界见[表格与高级数据库指南](表格与高级数据库指南.md)。

## 折叠列表与嵌套内容

输入 `/折叠` 并选择「折叠内容」，可以创建可编辑的折叠标题。单击左侧箭头收起或展开子内容；在标题中按回车进入第一个子内容。空折叠区也提供「点击添加」入口。子内容可以包含正文、标题、列表、待办、引用、代码和简易表格等；折叠只改变显示，不删除内容，重新打开页面仍保留折叠状态。

编辑时按制表键，把当前内容块和全部子内容嵌套到前一个同级块；按上档键加制表键退出一层。前一个同级块须支持包含子内容，代码、分隔线和简易表格不能作为父块。空列表项按回车先退出缩进，顶层空列表项再按回车变为正文。普通块按回车会在光标位置拆分，选择区外的文字保留；上档键加回车在当前块内换行。代码块、旧版整篇文档和含引用定义的源码段落保持原文编辑，回车直接换行。

块左侧手柄既能拖动，也能打开内容操作菜单；加号用于在该块之后插入新块。手柄菜单支持转换类型、添加子内容、创建内容副本、增加或减少缩进、上移、下移及删除。复制、移动和删除均包含整组子内容；删除后可以用工具栏撤销。带子内容的块不能直接转换成代码或简易表格等原子块，先调整子内容归属即可。已有正文转换为分隔线时，原文保留，另插入分隔线。

桌面拖动手柄时，蓝色横线表示放到目标前方或后方，中部蓝色边框表示嵌套到目标内。不能移入自身或自身的子内容。手机保留同一个操作入口，可以使用菜单的顺序与层级按钮，不依赖鼠标拖动。

## 就地斜线菜单

在正文开头或空白之后输入斜线，继续输入中文内容类型名称即可筛选，例如 `/折叠`、`/代码`、`/标题`。菜单显示在输入附近，上下方向键选择，回车执行，退出键取消；取消后原输入仍保留。代码和整篇源码编辑中不弹出斜线菜单。网页地址中的斜线不会触发菜单。

点击加号或手柄打开的菜单另有搜索框，可以输入筛选；制表键可访问内容类型和底部操作按钮，回车执行按钮。点击菜单之外或切换页面会关闭菜单，旧菜单不会修改新页面。插入图片、分隔线时，光标后方文字另保留为正文；取消文件选择不会改写当前内容。等待图片期间若页面已切换、同步刷新或继续编辑，旧操作停止并提示重新操作。

锁定或预览状态可临时展开折叠内容供查看，不会改写保存的折叠状态。编辑、拖动、复制和删除在锁定、预览及同步保护期间不可用。

完整层级、内容类型和折叠状态随轻笺结构化备份保存。独立文档导出使用可阅读的列表大纲表达层级，折叠标题带三角符号；再次导入纯文档不会还原全部折叠类型与状态，完整迁移应使用轻笺压缩备份。


## 选择多个内容块并批量操作

点击编辑工具中的「多选」后，勾选块左侧方框；再次点击同一方框取消。手机使用同一个入口。桌面也可按住控制键或命令键单击块或手柄追加选择，按住上档键单击选择连续范围。选中块后，上档键加上下方向键可扩展范围。拖动编辑器内块间或首块上方的空白处可以框选；拖至滚动区域边缘会自动滚动，已框到的起点内容仍包含在范围内。正文上的普通拖动用于选择文字。

底部工具条提供可见内容全选、类型转换、文字颜色、背景颜色、分栏、复制文本、创建副本和删除。「更多」提供上移、下移、缩进、退出缩进及待办完成与未完成操作。混选中修改完成状态只作用于待办。类型转换不满足子内容限制时，整批不修改并给出提示。分栏组不能直接转成普通正文，请先恢复单栏。

选择父块会连同全部子内容处理；即使子内容也被选中，计数和操作只计算最外层一次。折叠后单独选择的隐藏子块会退出选择，选中的父块仍包含整个子树。复制文本使用可阅读的文档格式，创建副本则保留完整结构、颜色与折叠状态。

离开输入框后可使用快捷键：控制键或命令键加 `A`选择可见内容，加 `C`复制文本，加 `D`创建副本；删除键删除所选，制表键缩进，上档键加制表键退出缩进，退出键结束多选。文本编辑框内保留原有文字快捷键；在内容输入框按退出键可转为选择当前块。页面菜单、属性弹层和分栏手柄不会误用正文删除快捷键。

切换页面或工作区会清理选择，选择不会保存到文件。锁定、预览及同步保护期间不能批量修改；保存失败仍保留当前草稿和重试入口。每次批量修改形成一次撤销记录。

## 拖拽分栏与列宽

选择连续、同一级内容后，在工具条选择两栏、三栏或四栏，会按文档顺序分配内容；不连续或不同层级的选择会提示先调整选择。也可用斜线菜单或块加号搜索「两栏」「三栏」「四栏」，插入空布局，再在列内添加内容。

拖动手柄到另一块左侧或右侧，蓝色竖线表示分栏落点；已有列中的左右落点会增加新列，最多六列。拖动多个选中块会将整组放入新列。蓝色横线仍表示上下排序，中部边框表示嵌套；空列中的按钮区域也可接收内容。不能把内容拖入自身子树。

鼠标拖动列间分隔手柄可调整相邻两列宽度；聚焦手柄后使用左右方向键微调，起始键均分该组列宽。调整期间只预览，释放后统一保存；退出键、指针中断或窗口失焦会取消本次调整。悬停分栏组可见「均分列宽」和「恢复单栏」，分栏组手柄菜单也提供对应入口。恢复单栏按列顺序保留全部内容，可撤销。

将某列原有内容全部移走或删除后会清理空列；剩下一列时自动恢复为普通内容。刚插入的空分栏保留，方便逐列填写。手机按列上下排列，不提供狭窄的列宽拖动手柄，可通过多选工具和菜单分栏或恢复单栏。

完整布局、列宽和嵌套内容保存在轻笺结构化备份中。独立文档导出只按列顺序输出内容，重新导入不会还原分栏。多设备同步此类页面时，各端应使用支持分栏的新版本。

## 检查与下载更新

从零点零点二版起，进入「设置 → 关于轻笺」，可以看到当前实际版本并点击「检查更新」。有正式新版本时，按照当前客户端系统和处理器提供对应安装包，点击后由系统浏览器下载；保存好笔记，再按系统提示安装。苹果手机仍需自行重新签名，模拟器包不能安装到手机。

原生客户端会在启动后后台检查，也会每小时检查一次；回到前台且距离上次检查超过一小时也会补查。可关闭「启动时自动检查更新」，该开关同时关闭周期检查。新版本提示不抢占正文光标；选择「暂不提醒此版本」后，不再提示这个版本，手动检查可重新显示。

新标签须先成功完成构建、测试与正式发布，才会显示为可更新版本。网络错误或访问受限会提示重试，离线笔记仍然可用；没有适合当前架构的安装包会明确说明。浏览器预览需自行选择目标平台，不把网页服务所在机器当作当前客户端。

零点零点一版没有更新功能，需要手动下载安装一次新版。安卓请覆盖安装同签名的新包，保留现有数据，不必先卸载。


## 手机数据库与内容块

在手机表格中点按记录名称打开详情，使用左上角返回按钮回到数据库；点按新建记录会立即打开该记录。视图标签和较宽的表格可以在各自区域横向滑动，页面本身保持正常宽度。

属性名称打开管理菜单，属性值用于编辑。选择、状态、多选及属性类型在底部面板操作；点按搜索框才弹出键盘，面板随键盘可见区域调整，选项太多时在面板内滚动。单选后自动关闭，多选即时保存后点完成。修改记录后返回会先保存，保存失败时保持当前记录并提供重试。

点按内容块左侧操作按钮打开底部菜单。常用的插入、复制、上移下移、缩进和删除直接显示，转换类型按需展开；在正文输入斜线也可以搜索插入。手机通过上移下移调整顺序，分栏按列堆叠；桌面仍可拖动。编辑工具条中的多选允许连续点选内容块并批量处理，结束后点关闭。

## 不懂版本管理也能同步

轻笺已经内置同步功能，手机、平板和电脑均不需要安装额外工具。你需要一个仓库服务账号、专用笔记仓库和访问令牌；所有日常操作都在轻笺里完成，不需要输入命令。

第一台设备的操作：

1. 点按同步，或在设置的工作区页面打开同步连接引导。
2. 在仓库服务网页创建一个专用私有空仓库，不初始化说明文件、忽略规则或许可证。
3. 创建仅授权该笔记仓库的访问令牌。GitHub 细粒度令牌选择该仓库，仓库内容权限设为读写；GitLab 令牌选择 `write_repository`。组织可能另有审批要求。
4. 选择上传当前工作区，粘贴仓库的完整加密网页地址，填写用户名和令牌，点击连接并同步。默认分支通常无需修改。

在另一台设备选择下载已有同步笔记，填写同一仓库地址和有效授权，下载到新的工作区。本机原有工作区保留，不会被下载操作覆盖。每个工作区可以连接独立仓库。

换设备前先同步，另一台设备开始编辑前也先同步。应用自动处理本地版本、上传与下载，不会自动强制推送。网络或认证失败时保留本地笔记并明确报错。两台设备各自修改不同笔记时自动合并；同一笔记有不同修改时，在应用内核对摘要并选择版本。不要通过卸载应用处理同步问题。

访问令牌仅在本次应用会话有效，关闭应用后需重新填写。仓库地址本身不能包含令牌、密码或查询参数。更换仓库地址会清除旧认证，避免把旧授权发给新站点。

授权说明可参考[GitHub 官方帮助](https://docs.github.com/zh/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)和[GitLab 官方帮助](https://docs.gitlab.com/user/profile/personal_access_tokens/)。


## 同步冲突与工作区管理

从本版开始，已有本地工作区也能直接关联已有笔记仓库。首次连接遇到独立历史时，应用会显示本机和远程的笔记数量，并要求明确选择：

- **合并两边，逐项选择冲突**：不同笔记保留两边修改；同一笔记或同名附件同时修改时，逐项选择本机或远程的整个文件版本。
- **整个工作区以远程为准**：当前工作区采用远程全部笔记和附件，本机原内容保存在同步恢复点。
- **整个工作区以本机为准**：把本机整份工作区同步到远程。其他设备同步后会采用此内容，原远程版本保留在恢复点和历史中。

日常同步中，不同笔记的分叉自动合并。同一篇笔记即使修改不同段落，也会交由你选择整篇版本；数据库同样按整个数据库页面选择，不承诺逐格自动合并。面板每边最多显示十二处变更正文或数据库值摘要，每项最多五百字；完整版本可从恢复点恢复。

应用选择前会重新拉取并核对双方版本。如果任一端或仓库配置又有变化，会停止旧选择，点击「重新检查双方版本」后重新核对。父子层级组合无效时也不会应用，可以改选整个工作区版本。应用后的合并提交保留双方父版本，采用普通推送，远程又有新提交时不会强制覆盖。

### 找回同步前内容

打开「工作区菜单 → 管理工作区 → 同步恢复点」，选择恢复本机或远程版本。恢复会创建独立的本地工作区，可以核对、导出和整理；不会覆盖当前笔记，也不会自动关联远程。恢复点只在保存它的本机存在，删除该工作区的全部本机数据也会删除恢复点。

### 移除不需要的工作区

打开「工作区菜单 → 管理工作区」，点击对应工作区的「从此设备移除」，核对名称、笔记数量与空间后确认。移除只影响这台设备，远程仓库和其他设备不变。最后一个工作区也能移除，随后会创建没有示例笔记的空白工作区。

已移除的工作区列在同一个管理页面，可恢复。移除本身保留数据，因此仍占空间；需要释放空间时，在「已移除的工作区」选择「永久删除并释放空间」，再次勾选确认。永久删除包括笔记、附件、版本历史及同步恢复点，无法撤销。若空间清理中断，可从列表继续清理剩余文件。


## 国内仓库连接与本机测试修订

同步引导新增国内仓库平台选择，提供[创建 Gitee 仓库](https://gitee.com/projects/new)和[设置私人令牌](https://gitee.com/profile/personal_access_tokens)入口。填写完整仓库地址，例如 `https://gitee.com/username/notes.git`。平台选项提供地址示例，实际连接和认证目标始终由输入的地址决定，不会自动改写已有地址或向其他站点发送认证。

Gitee 使用私人令牌时请填写真实用户名，通常可在个人主页的地址中核对，不要填写显示昵称或仓库所属组织名。令牌需要目标仓库读取和写入权限。开启双因素认证后，应按[官方说明](https://blog.gitee.com/2026/07/14/gitee-双因素认证：为代码资产加上第二把锁/)使用私人令牌代替密码。令牌可在本机系统安全凭据库记住，不填写到地址中。

已有仓库的分支以仓库页面实际显示为准，不要固定假设为某个名称。如果提示当前分支不存在，但列出了其他远程分支，应用会停止，不悄悄创建另一条分支。可选择「下载已有同步笔记」，展开高级设置并填写实际分支，创建独立工作区，原有工作区保留。

电脑和安卓原生端的失败现在统一为可读错误，保留真实原因；缺失原因时显示中文兜底，错误消息中的认证信息会隐藏。不会用连接设置保存成功冒充实际同步成功。本次修订先以保持原版本号的本机苹果桌面测试包验证，不创建新版本或发布标签；真实私有仓库认证需使用自己的有效权限测试。


## 在本机记住工作区认证

首次连接时填写仓库真实用户名和访问令牌，勾选“记住此工作区的认证”。原生应用默认勾选，保存成功后显示“已安全记住认证”。以后重复同步、关闭再打开应用，都会自动读取对应认证，无需重复填写。已记住时令牌输入框始终留空，保存或重新连接时可以沿用；更换账号时必须同时输入新令牌。

苹果电脑使用系统钥匙串，微软桌面使用凭据管理器，安卓使用系统密钥库加密应用私有存储，苹果移动端使用系统钥匙串，桌面开源系统使用桌面安全凭据服务。需要系统解锁或授权时，按系统提示操作；拒绝授权时会明确显示保存或读取失败，不会把令牌改为明文存储。没有安全凭据服务的环境可取消勾选，仅本次运行使用。浏览器开发服务不支持长期记住认证。

在“设置 → 工作区与仓库 → 工作区认证”中可查看状态、替换认证或选择“忘记此工作区的认证”。忘记后，下次同步需要重新填写。不同工作区与不同完整仓库地址分别保存认证，更换仓库地址或移除工作区会清除旧认证，改名不会清除。认证不会随笔记同步到其他设备，每台设备首次设置一次。

旧版本未长期保存的用户名和令牌无法自动恢复，安装本次测试包后需要先填写一次。访问令牌过期、撤销或仓库权限改变时，仍需更新认证。


## 自动同步与网络期间草稿

本节功能目前随测试构建提供，尚未正式发布。

关联仓库并保存认证后，工作区默认开启自动同步。打开应用约一秒后检查一次；回到前台、窗口重新获得焦点或网络恢复时检查；前台每两分钟检查一次。编辑自动保存并停止操作约四秒后上传。未配置仓库时只保存在本机。可以在「设置 → 工作区 → 自动同步」关闭当前工作区的自动同步，手动同步仍可使用。

自动同步等待网络时可以继续输入正文和数据库属性，当前草稿先留在编辑器及本机恢复记录中。远端未改变这些内容时，仅推进版本信息，再保存后续输入；双方都修改时显示顶部冲突提示，暂停自动保存和同步，点击核对后明确选择保留本机、保留已同步版本，或把草稿另存为副本。没有默认选择。生成选择预览和执行选择期间短暂保护编辑，防止确认的快照落后于最新输入。

草稿恢复点包含完整正文、数据库属性及引用的本机附件，存放在应用数据目录的 `sync-draft-backups` 中，不上传到远端仓库。「设置 → 工作区 → 同步草稿恢复点」可以恢复为独立副本，不覆盖当前页面。来源附件若被远端删除，恢复点仍保留原字节；同名附件内容不一致时拒绝覆盖并显示原因。恢复点会占用额外本机空间，工作区磁盘统计暂不包含此目录；移除工作区时保留，明确永久清理已移除的工作区时一并删除。

离线时继续本地保存，联网后再试；同步失败按十五秒起逐步延长到五分钟重试，继续输入不会反复发请求。同步异常不会显示成功，点击顶部状态可查看原因或立即重试。认证失败时在设置中检查真实用户名、访问令牌及仓库权限。多窗口通过同源锁减少重复同步，过时窗口保存也须核对版本，不能静默覆盖另一窗口内容。

自动同步只在应用运行且处于前台时工作。手机切后台、被系统结束、关闭应用或设备休眠后不保证继续同步；离开前可确认顶部已完成状态。首次连接已有仓库及历史分叉仍需按引导选择，不强制推送，不替代备份。


## 数据库记录批量处理（测试构建）

勾选表格行或其他视图卡片的复选框，工具条即可编辑同一属性、导出所选、复制或移除。表头全选当前视图，按住上档键可以连续扩选；切换搜索、筛选或视图会取消选择。手机点选复选区域，批改在底部弹层完成。

多选、人员与关联可追加或移除选项，清空需明确选择。含独立子页的记录暂不支持整批复制；移除数据库行会保留独立子页面和正文，并先保存本地版本。详细范围与快捷键见[数据库批量操作说明](表格与高级数据库指南.md#数据库记录多选与批量操作测试构建)。本节不代表已发布版本具备该功能。
