# 使用指南

## 开始记录

第一次打开轻笺会创建「个人笔记」工作区，并提供几篇示例。点击「新建页面」，输入标题，然后点击正文开始写作。修改约在输入停止后自动保存；也可使用保存快捷键立即保存。

正文支持 Markdown 的加粗、斜体、删除线、代码与链接符号。编辑状态保留符号，退出内容块或切换到预览后显示格式。输入 `/` 选择内容块；输入完成后按回车创建下一块，换行使用换行组合键。代码块中的回车直接换行。

桌面可以拖动块左边的手柄排序。手机点击块左侧的加号打开菜单，再选择上移、下移或删除。页面标题中的图标与封面可以更换，封面目前提供内置配色。

## 整理页面

使用页面左侧的加号创建子页面，也可以在「所属页面」中移动现有页面。页面层级不能形成循环。收藏页面会显示在导航收藏区，标签用于工作台筛选。

「更多操作」提供复制、宽版、锁定、Markdown 导出和移入回收站。删除父页面时子页面一起进入回收站；恢复时保留内容。锁定只是防误编辑，不是加密或访问权限。

页面名称链接的写法为 `[[页面名称]]`。导入或程序生成的稳定链接使用页面标识。右侧目录从标题块生成；关联信息显示哪些页面引用当前页面。手机和窄窗口会隐藏右侧辅助栏。

## 表格与数据库

普通页面可以从内容菜单插入「简易表格」，直接编辑单元格和增删行列。需要筛选、排序、计算或关联时，选择工作台或导航里的「新建数据库」。

数据库提供表格、看板、列表、图库和日历视图，支持多选、基础公式、跨数据库关联、汇总以及记录详情。模板中的「高级数据库示例」提供可直接体验的计算数据。

详细步骤、公式语法和兼容边界见 [表格与高级数据库指南](表格与高级数据库指南.md)。完整的 Notion 公式、双向关联、命名视图与多人权限尚未实现。

## 配置多个仓库

点击导航上方的工作区名称，选择「添加工作区」。填写中文名称、远程仓库 HTTPS 地址与分支。

- 创建新仓库：创建本地独立工作区，可推送到空的远程仓库。
- 克隆已有仓库：读取所选远程分支中的轻笺笔记文件。
- 留空远程地址：仅在本地保存，之后可到设置补充地址。

已有工作区不直接切换分支。需要使用其他分支时，创建工作区并克隆目标分支。每个工作区的配置、笔记与 Git 历史彼此独立。

私有仓库在工作区设置中填写用户名与访问令牌。GitHub 令牌需要目标仓库内容的读取和写入权限；GitLab 令牌需要仓库读取和写入权限。令牌只保存在本次会话内，退出后需重新设置。不要把令牌放进仓库地址。

点击「保存版本」创建本地版本。点击「同步」提交当前修改并与远程交换内容。远程没有配置时仍可保存本地版本。同步期间暂时保护编辑内容，完成后恢复编辑。

## 分叉与失败

如果两台设备分别修改后产生分叉，应用会停止同步并保留本地提交。可以在桌面的笔记仓库中用 Git 手动合并，再返回应用同步；或者新建工作区克隆远程版本，比较并迁移需要保留的内容。

应用不会强制推送，也不会为了同步成功而重置本地历史。认证或网络失败不影响已有本地版本。保存失败时当前输入与恢复草稿仍保留，应先重试保存，再离开页面。

## 导入 Notion

在 Notion 的导出菜单中选择 Markdown 与 CSV 或 HTML，勾选包含子页面，下载导出压缩包。轻笺里点击「导入笔记」，选择文件并查看报告。

安卓文件提供器可能不返回文件名。压缩包可按内容自动识别；直接选择文本、表格或网页文件时，可以在导入窗口指定对应格式。

首版支持中文页面、基础内容块、子页面、页面间链接、附件和 CSV 数据库记录。评论、权限、公式逻辑、关联汇总以及复杂布局不能从导出文件完整还原。导入后应核对重要笔记和数据库，并保留原导出包。

大于一百二十八兆字节的导出内容请拆分导入。导入不会覆盖现有笔记；重复导入会创建新的页面，但相同附件尽量复用。

## 导出与恢复

设置中的「导出笔记」生成完整压缩备份，包含结构化页面、Markdown、数据库表格及附件。恢复时通过「导入笔记」选择这份压缩包。回收站页面不包含在导出备份中，但仍保留在原工作区。

五个平台使用系统保存对话框选择导出位置。单页 Markdown 导出适合阅读和分享，不包含完整数据库及附件副本。需要保留所有历史时，以 Git 仓库克隆为准。

## 外观和磁盘

设置里可以切换浅色、深色、跟随系统主题，以及简体和繁体中文。语言设置影响界面，已有正文不会自动翻译。

磁盘统计显示当前工作区实际文件大小，分为笔记、附件和 Git 历史。它不包含应用安装体积，也不包含系统网页内核的共享缓存。大量附件和长期版本历史仍会增加磁盘占用；首版不自动压缩历史或永久清理附件。
