## 核心覆盖

1. 保存和重启读取、多个工作区隔离、旧版本拒绝覆盖。
2. 页面循环层级阻止、父子页面回收站和恢复。
3. 本地真实 Git 提交、版本历史、恢复、远程推送、克隆和分叉保护。
4. Notion 子页面、内部链接、图片附件和数据库表格导入。
5. 路径越界拒绝、损坏备份正常返回错误、失败后仍可使用工作区。
6. 结构化备份恢复，避免重复导入辅助格式。
7. 文本、表格、网页、数据文件和压缩附件的原始字节保留。
8. 实际文件大小保护，以及远程超限页面在更新前被拒绝。
9. 无扩展名手机压缩包导入、无扩展名图片识别。
10. 循环备份层级拒绝、HTML 正文保留与活动脚本剔除。
11. 当前平台的 HTTPS 证书初始化。
