# 轻笺功能对齐与多端同步改进清单

核对日期：二〇二六年十月二十八日。

本清单按“继续补齐接近 Notion 的功能”理解，并单列多端数据同步增强。它是待办与建议，不代表已经实现，也不代表授权一次性改造全部功能。

当前正式公开版为零点零点六，已交付测试包为十月二十二日的零点零点七。十月二十八日新增的属性键盘选择、稳定搜索与图库复选框修复已在本机匿名样本验证，尚未重新打包，不能算作已安装测试包的能力。

## 已有能力，不重复列为缺失

- 页面树、父子页面、图标封面、页面链接、目录及反向链接。
- 常用内容块、嵌套、折叠、多选批量操作、拖动分栏、撤销重做。
- 表格、看板、列表、图库、日历五种数据库视图，命名视图、组合筛选、多层排序和分组。
- 二十二种本地属性，基础受控公式、单向关联、汇总和受控赋值按钮。
- 导入记录的独立子页、结构化属性、侧边预览，以及记录批量操作。
- 内置模板、结构化备份、历史版本、多工作区、内置仓库同步、自动同步及冲突选择。

“已有”只表示存在对应实现，仍以具体测试包和验收范围为准；例如内置模板不等于用户模板库，基础关联不等于双向关联，普通记录、模板和日期范围的本轮新增实现以文末验收进度为准。

这里列的是现有 Git 多端同步的增强。与 Notion 云端直接双向同步尚未实现；当前支持其导出文件的导入迁移。直接连接需要另行设计授权、字段映射、删除与冲突处理。

## 需要单独确定范围的方向

- 评论、成员权限和多人实时协作：需要身份、授权及并发编辑方案，不能把当前本地人员名单当作权限系统。
- 笔记公开分享与发布页：与产品官网建设分别处理，需要明确可公开的内容和附件范围。
- 智能总结、翻译及填充：按既有约定推迟，不擅自引入付费服务、模型密钥或联网处理笔记。
- 提醒、后台任务、全局快捷键与开机自启：分别评估系统能力和用户设置，不将桌面常驻误称为后台持续运行。

## 建议顺序

先完成十月二十八日已有改动的交付验收，再按“普通记录完整正文 → 模板 → 日期范围 → 关联数据库视图 → 双向关联”分批推进。原位富文本独立作为持续改造项，不与存储、关系及同步大改绑在同一批。

可靠性检查贯穿每一批；实际遇到保存失败、编辑丢失或同步覆盖风险时，优先修复再扩展功能。用户随后已授权按前三项顺序实施。正文、模板和日期范围已加入本轮测试源码并在匿名数据验证；尚未重新打包或正式发布，关联视图与双向关联仍是后续待办。
