# 轻笺 0.0.1

首个公开版本，本地优先的跨平台笔记工具。默认中文，使用共享界面与共享核心，支持多个独立仓库同步。

## 本版功能

- 页面树、子页面、收藏、图标、封面、全宽布局、侧栏折叠及回收站。
- 内容块编辑、文档粘贴、折叠与嵌套、多选批量操作、拖拽分栏、撤销重做。
- 数据库表格、看板、列表、图库、日历、命名视图、组合筛选和多层排序。
- 二十二种本地数据库属性、基础公式、关联汇总和记录正文。
- 原笔记工具导出的压缩包、文档、表格与网页导入，以及结构化备份迁移。
- 独立工作区、本地版本历史、仓库克隆、快进更新与普通推送；分叉时停止同步并保留双方内容。
