# 轻笺 0.0.5

补上手机与电脑的工作区移除、同步冲突选择和恢复入口，继续使用内置同步库，无需安装额外工具。

## 同步不再因历史分叉直接卡住

- 新装手机的默认工作区可以直接关联已有笔记仓库，遇到独立历史时选择本机优先、远程优先或合并。
- 两端修改不同笔记时自动合并；同一篇笔记、数据库页面或同名附件发生不同修改时，核对双方摘要并逐项选择整个文件版本。
- 数据库冲突展示实际变更值摘要；不会把结构化数据当文本强行拼接。
- 选择前重新拉取；本机、远程或仓库配置变化时拒绝旧选择，支持重新检查。
- 覆盖前保留双方完整恢复点；合并提交保留双方父版本，普通推送，不强制覆盖远程历史。
- 保留冲突页面时保护其仍引用的附件。合并后的修订号推进，旧窗口不能覆盖已选择的版本，删除的页面也不会被旧草稿静默复活。

## 工作区管理

在工作区菜单或设置中打开「管理工作区」。支持从此设备移除、恢复已移除工作区、再次确认后永久删除并释放空间；远程仓库与其他设备不受影响。最后一个工作区移除后创建空白工作区。

同步恢复点可恢复到独立本地工作区，不覆盖当前笔记。工作区移除保留数据和恢复点，仍占空间；永久删除后不可恢复。空间清理中断时保留重试入口。

## 使用边界

同一篇笔记或数据库同时修改时，目前选择整篇版本，不提供实时协同和逐格自动合并。摘要限制为每边十二项、每项五百字，完整内容保留在恢复点中。认证授权仍仅本次会话有效。

沿用固定安卓签名，覆盖升级时请勿先卸载。移动端原生构建与启动验证继续在云端执行，苹果手机包仍需自行签名。
