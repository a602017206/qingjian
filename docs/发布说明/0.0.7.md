# 轻笺 0.0.7

新增思维导图、知识图谱和自由节点图，支持在文档中直接预览图表；并完善数据库记录正文、模板与日期范围。

## 思维导图与自由节点图

- 思维导图支持编辑分支、调整层级和关联页面。自由节点图支持自由摆放节点、多对多连线、方向和标签。
- 普通文档可以插入已保存图表的预览，并放大查看；移动端自由节点图支持触屏拖动、缩放和平移。
- 图表结构随页面保存、同步和结构化备份。同步冲突时选择处理方式，双方数据保留在恢复点中。

## 知识图谱

- 查看工作区全局图谱，或从页面查看一跳、两跳的局部关联；可筛选关系类型、页面和标签。
- 图谱画布随节点数量扩展，支持拖动节点。位置保存在当前设备，并按工作区和图谱范围隔离；位置不进入 Git 同步或结构化备份。

## 数据库与编辑

- 普通数据库记录支持完整内容块正文；新增页面模板、记录模板与默认模板。
- 支持日期范围、时间及时区，保留旧版单日日期的兼容读取；改善属性选择、搜索和编辑稳定性。

## 升级与兼容

- 升级前请导出结构化备份，并先升级所有参与同步的设备。旧版客户端不认识新图表格式，用旧版编辑或恢复图表页面可能丢失图表数据或页面引用；请避免使用旧版处理新图表。
- 安卓请覆盖安装，不要先卸载，以免清除本地数据和认证。苹果手机真机包需要自行签名。
- 苹果桌面应用使用临时签名且未公证，系统可能要求再次授权钥匙串。移动端浏览器模拟验证不能替代实体设备和原生文件选择器的验收。
