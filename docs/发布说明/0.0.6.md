# 轻笺 0.0.6

安卓和桌面可以记住工作区认证，退出后再次打开无需重复输入用户名和访问令牌。本版继续沿用固定安卓签名，可覆盖升级。

## 安全记住认证

- 原生应用连接仓库时默认勾选“记住此工作区的认证”，可自行取消。
- 安卓通过系统密钥库加密应用私有存储；苹果电脑和苹果移动端使用系统钥匙串，微软桌面使用系统凭据管理器，开源桌面系统使用桌面安全凭据服务。
- 已记住时显示保存状态与用户名，令牌保持隐藏。重新打开、重复同步、令牌输入框留空时可沿用已有认证；更换用户名需同时填写新令牌。
- 设置中新增“忘记此工作区的认证”；更换完整仓库地址或移除工作区时清除旧认证，改名不清除。
- 不同工作区及仓库地址隔离认证。令牌不写入笔记、同步仓库、源码或浏览器本地存储，不会同步到其他设备。
- 系统安全存储或配置保存失败时明确报错，不假报保存成功。浏览器开发服务仅保留本次运行认证。

## 国内仓库与同步反馈

- 增加国内仓库的创建、授权入口与地址示例，完善真实用户名、私人令牌和分支说明。
- 国内仓库使用私人令牌时校验真实用户名，避免空用户名导致反复认证失败。
- 修复原生同步错误丢失原因、显示未定义值的问题；保留实际错误并脱敏认证信息。
- 远程非空且当前分支不存在时停止并列出已有分支，不静默创建空分支。可以下载到新工作区并指定实际分支。

## 验证与升级

发布流程包含共享核心与界面回归，以及安卓十六普通页和十六千字节页模拟器的冷启动验证。仅测试包启用匿名认证验证：保存后强制结束进程，重新打开读回并删除，再次启动确认已忘记；正式安装包不包含此测试开关。

旧版未保存的认证无法恢复，升级后请填写一次真实用户名及访问令牌并勾选记住。授权过期、被撤销或权限不足时仍需更新令牌；系统安全服务锁定或拒绝授权时，请按提示处理。

安卓请覆盖安装，不要先卸载，以免清除本地笔记和认证。模拟器验证不能替代三星等具体机型实测，建议在目标设备验证重启后的同步。苹果手机包仍需自行签名。
