# 轻笺 0.0.2

新增客户端更新检查，并修复安卓原生库的页对齐兼容缺口。

## 更新功能

「设置 → 关于轻笺」显示实际版本、系统与架构，可检查正式新版本、查看发布说明并下载对应安装包。原生客户端启动后和每小时后台检查，回前台时按一小时间隔补查；支持关闭自动检查和暂不提醒当前新版本。提示不会抢占正文焦点，不会静默安装。

仅检查本项目公开正式发布版本。新标签须等待全部构建、测试和发布完成；草稿和预览版本不提示。网络错误、限流、缺少平台文件或不支持的架构会明确显示，不误报最新版，不改动笔记。浏览器预览需要手动选择下载平台。

首版没有更新入口，需要手动下载并安装这一次新版。安卓保留原签名，可覆盖升级，请保留本地数据。苹果桌面压缩包仍附首次打开中文说明；苹果手机包仍需使用者自行签名。

## 安卓启动验证

已在云端复现启动画面后退出：启动钩子调用了安卓依赖不支持的文件证书加载接口，导致原生异常终止。此版改为从内存装载内置根证书，保留证书与主机验证。旧安卓包另有原生库加载段仅四千字节对齐的问题。此版同时设置原生链接页对齐和压缩包对齐，签名前校验所有原生库；新增发布模式模拟器冷启动门禁，保留启动日志、界面树和截图。模拟器不等于三星手机实机，具体设备若仍在启动画面后退出，请反馈系统错误报告。

## 下载

平台文件名沿用首版：微软桌面、苹果桌面两种处理器、Linux 安装包与便携包、安卓固定签名包、苹果手机模拟器包及未签名真机包。`SHA256SUMS.txt` 提供全部八种文件的摘要，版本按标签独立保存。
