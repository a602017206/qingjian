# 轻笺 0.0.3

此标签仅用于云端验证，没有公开发布安装包。正式修订版见[零点零点四](0.0.4.md)。

改善手机数据库、属性和内容块操作，增加无需安装外部工具的多设备同步引导。

## 手机编辑

- 表格标题可直接点按打开记录，新增记录后立即进入详情，返回入口明确标注数据库。
- 属性值、属性菜单和内容块操作从底部展开，根据可见视口避开软键盘，支持面板内滚动。
- 常用触控入口扩大，视图标签可横向滚动，数据库表格在自身区域横向滚动。
- 内容块菜单优先显示常用操作，按需展开类型选择，支持在下方插入、缩进、移动、折叠及多选批量操作；斜线菜单继续跟随编辑光标。
- 手机分栏仍按列堆叠，桌面保留原有布局与拖动方式。

## 同步引导

轻笺内置同步库，手机和电脑均无需安装外部版本管理工具，也不需要输入命令。首次点击「同步」即可按中文步骤准备私有仓库、访问授权并连接。

第一台设备连接新建的空仓库，上传当前工作区；新设备选择下载已有笔记，创建独立工作区，保留本机已有笔记。支持多个工作区分别连接不同仓库。失败时保留输入并明确提示，不把连接设置保存误报为同步完成。

访问授权目前仅在本次应用会话有效，退出后需重新填写。仓库地址不能包含令牌或密码；更换远程地址时清除旧会话认证，认证回调拒绝跨站或降级请求。令牌不写入笔记仓库及浏览器存储。

换设备前及另一台设备开始编辑前，请先同步。网络失败时本地笔记保留；历史分叉会停止并提示，当前不会自动合并或强行覆盖。

## 下载与验证

沿用八种平台文件名及统一摘要清单。已有更新入口的客户端可检查新版本，并按系统与架构下载对应文件。安卓使用原固定签名覆盖升级；苹果手机包仍需自行签名。

手机交互通过隔离的触控浏览器和软键盘视口模拟回归；原生构建和安卓启动门禁在云端执行。具体手机实机体验仍需使用者确认。
