# 产品设计与功能范围

## 目标

轻笺面向需要整理个人知识、希望掌握数据并控制磁盘占用的用户。用户无需创建云端账号，可以在本地记录、整理和检索笔记；需要跨设备时，通过自己的 GitHub、GitLab 或兼容 HTTPS 的 Git 服务同步。

数据仓库是笔记仓库，源码仓库是构建应用的仓库，两者用途不同。可以配置多个笔记工作区，每个工作区对应一个独立仓库。应用源码暂时只在本机保存。

## 跨平台原则

桌面和移动端不维护不同的编辑页面，也不分别编写两套存储与导入服务。所有平台使用相同的网页模块、样式、模板、国际化字典和 Rust 核心。Tauri 提供系统窗口、数据目录和文件选择接口。窄屏采用可展开导航，编辑器保留相同的色彩和内容结构。

文件选择后的内容地址、根证书来源和安装包生成过程存在系统差异。这些差异集中在系统接口与初始化配置，不进入笔记数据格式。

## 已实现的功能

| 范围 | 当前能力 | 具体边界 |
| --- | --- | --- |
| 工作台 | 最近编辑、页面列表、搜索、收藏和标签筛选 | 检索当前工作区，暂不跨仓库聚合 |
| 页面管理 | 多级页面、标题、图标、封面、移动、收藏、标签、复制、宽版和锁定 | 封面使用内置配色，锁定用于界面防误触 |
| 删除恢复 | 父子页面一起移入回收站，批量选择、恢复及永久清理 | 清理共享附件时核对引用，版本历史另行保留 |
| 内容块 | 文本、六级标题、列表、待办、引用、提示框、代码、分隔线、折叠内容、附件 | 支持独立折叠标题、多层嵌套与简易表格；复杂分栏暂未实现 |
| 行内格式 | 文档粘贴、加粗、斜体、删除线、行内代码和链接预览 | 编辑时使用 Markdown 符号，预览时显示格式 |
| 编辑操作 | 就地搜索斜线菜单、子树拖动复制删除、键盘缩进、上移下移、撤销重做 | 撤销保留当前页面最近六十次编辑快照 |
| 页面关联 | 专用页面链接、按标题链接、反向链接、自动标题目录 | 重命名后按标题书写的链接需更新；专用标识链接仍有效 |
| 数据库 | 五种布局、命名视图、组合筛选、多层排序、独立显示属性、记录详情 | 视图配置随页面保存；基础公式和同工作区单向关联汇总 |
| 属性类型 | 二十二种本地属性，含状态、人员、媒体、系统信息、按钮和位置 | 人员是本地名单；日期为单日；公式为受控子集，智能填充待后续接入 |
| 模板 | 空白、每日记录、会议纪要、阅读笔记、项目计划和高级数据库示例 | 当前为内置模板，暂不提供用户模板库 |
| 保存 | 自动本地保存、版本覆盖保护、恢复草稿 | 草稿恢复依赖应用网页存储；主笔记持久保存在文件中 |
| 版本管理 | 本地 Git 提交、页面历史、恢复版本 | 每页显示最近五十次有效内容变更 |
| 仓库同步 | 多仓库、HTTPS 认证、克隆、快进更新和推送 | 分叉时停止同步；需要人工合并或另建工作区克隆 |
| 迁移 | Notion 压缩包、Markdown、CSV 和基础 HTML | 导出缺失的评论、权限、公式及关联汇总无法还原 |
| 备份 | 结构化页面、Markdown、CSV、附件打包 | 完整恢复请使用轻笺压缩备份；独立 Markdown 不是完整数据库备份 |
| 外观与语言 | 浅色、深色、跟随系统；简体与繁体中文 | 新语言可增加字典；导入正文保留原内容 |
| 磁盘管理 | 当前工作区笔记、附件和历史的真实文件用量 | 不包含应用安装体积和系统网页内核的共享缓存 |

## 视觉设计

浅灰导航、白色正文、蓝灰边界、靛蓝选中态和青绿本地状态。字体采用系统中文字体，不下载远程字体。文档是界面中心，目录与关联信息在空间充足时显示。工作区底部展示真实磁盘用量和本地状态。

移动端使用同一页面结构：导航抽屉、紧凑的顶部工具、可以横向滚动的数据库、原生文件选择和保存对话框。内容块提供顺序按钮，减少对鼠标拖动的依赖。

## 后续路线

1. 完成安卓、苹果真机的文件选择、键盘、安全区域和 Git 认证实测，补齐签名发布流水线。
2. 提供分叉冲突的可视化对比与逐项合并、持久化安全凭据和多仓库聚合搜索。
3. 增强内容块：分栏、数学公式、语法高亮、用户模板和远程图片缓存管理。
4. 增强数据库：日期区间、双向关联、关联数据库视图、自动化与完整公式兼容。
5. 评估评论、权限、协作编辑与公开发布。这些功能不能仅靠 Git 快进同步等同实现。

这些是后续计划，不代表当前已经具备。首次交付以可运行首版和可靠的数据迁移、存储及同步路径为范围。


## 批量管理与空间清理

侧栏和工作台支持批量选择并移入回收站，回收站支持单项、所选和全部永久清理。确认预览包含页面、附件与字节数，剩余页面共享附件保留。清理实际文件并刷新空间统计，不改写或强推 Git 历史。整体重绘维护侧栏可见页面和滚动位置。
