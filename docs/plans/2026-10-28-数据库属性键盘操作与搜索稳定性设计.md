# 数据库属性键盘操作与搜索稳定性设计

依据轻笺零点零点七测试版现有代码整理。用户已选择“按推荐方案推进”，确认本轮范围。

## 问题与本轮目标

现有数据库属性选项可以搜索、点击和即时保存，但搜索框回车优先触发创建选项，缺少上下键定位与清晰的活动项。工作台搜索和数据库快速搜索通过重新渲染页面更新结果，存在替换正在组词的输入框的风险。本轮优先完善高频选择与搜索，保留既有数据格式和保存、冲突处理方式。

## 推荐方案

属性选择新增上下键循环定位、回车执行活动项；默认定位已有匹配项，创建新选项作为明确的最后一项。无匹配项时仍可回车创建。单选或状态选择后关闭，多选、人员及关联连续切换项目并保留搜索框焦点。取消候选不触发操作，正常退出维持现有弹层行为。

为活动项提供可访问状态与自动滚入可见区域；输入框通过活动后代标识当前项。桌面和手机共用同一套交互，触控继续使用既有选项入口。若当前属性、记录或工作区已变化，沿用上下文校验拒绝旧弹层写入。

工作台和数据库搜索更新结果时保留输入框节点、焦点、光标和组词过程。数据库搜索仍只是本机临时查询，不写入共享视图。过滤条件变化沿用清空记录选择的保护，搜索不改写笔记正文或属性值。

## 其他路线与取舍

- 普通数据库记录升级完整内容块正文，能补齐记录与页面体验，但需要设计记录关联、旧正文保留和原子保存，适合作为后续独立批次。
- 优先推进原位富文本，能减少编辑时的符号暴露，但涉及复杂文档兼容、光标和输入法，范围更大，应单独评估。
- 只修复搜索稳定性，变更范围最小，但本批不新增属性键盘操作。

## 验收范围

先用匿名样本复现已有问题，再增加失败回归。覆盖上下导航、回车选择已有项与明确创建、多选连续操作、无匹配项、组词保护、鼠标和触控、上下文过时拒绝；搜索检查节点身份、焦点、光标、中文组词及筛选后选择隔离。运行相关数据库、输入法、编辑和自动同步回归，核对没有破坏原有保存保护。

版本保持零点零点七，不创建标签或正式发布。移动端原生编译与模拟器仍只允许在 GitHub 执行，不读取真实笔记、私人仓库认证或签名密钥。本次只验证实际执行的范围，不以浏览器测试冒充手机实机验收。

## 实施计划

### 一、建立失败回归

新增 `tests/property-options.test.mjs` 与 `tests/search-input.test.mjs`，验证选项过滤、已有项与创建项的区分、循环活动项、组词期间延迟更新及输入框脱离后取消更新。新增 `tests/e2e/property-keyboard.mjs` 与 `tests/e2e/search-stability.mjs`，使用隔离匿名数据检查真实界面节点、焦点、光标、键盘选择、触控与五种数据库布局。先运行并确认失败原因与现有问题一致。

### 二、实现属性选项交互

新增 `ui/web/property-options.mjs`，集中处理可选项和活动项计算；在 `ui/web/app.mjs` 的属性弹层中接入键盘及指针活动项、明确创建入口与可访问状态。沿用原有提交、上下文核对和失败提示，兼容既有复选框及测试定位。`ui/web/i18n.mjs` 增加简繁中文键盘提示，样式在 `ui/web/style.css` 中补充。

### 三、保持搜索输入稳定

新增 `ui/web/search-input.mjs`，统一组词防护、延迟刷新和已移除输入框的旧任务取消。在 `ui/web/app.mjs` 中将工作台搜索更新限制为结果表，将数据库搜索更新限制为工具栏之外的结果区域。重新绑定新结果控件，恢复原有滚动并执行批量选择范围同步，保留输入框及编辑区节点。

### 四、验证与记录

运行新增单元和界面测试，再运行 `npm test`、`npm run check`、`npm run build`、`npm run release:check`、`node scripts/check-docs.mjs` 与 `git diff --check`。按实际影响回归已有属性、数据库批量、命名视图、输入法、编辑稳定、手机布局及匿名自动同步流程。将新增界面验证接入现有脚本与共享 CI，更新中文指南、验证报告及当天唯一日记，明确尚未重新打包和实机验收的范围。
