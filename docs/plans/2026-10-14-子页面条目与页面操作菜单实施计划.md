# 子页面条目与页面操作菜单实施计划

**目标：** 依据用户两张截图，将普通页面中的子页面显示为带图标、颜色、下划线的紧凑条目，补齐可搜索的页面操作与子菜单。

**架构：** 使用同一套网页界面实现桌面与移动端交互。纯页面链接作为页面条目渲染，混排正文保持原来的文字编辑；不改写页面身份或删除正文。菜单复用已有保存、回收、移动和版本冲突保护。网页导入恢复导出文件中明确存在的图标及条目颜色，不猜测缺失样式。

**技术：** 共享网页界面、原生窗口接口、共享笔记核心。

1. 在 `tests/page-links.test.mjs` 增加纯页面条目、转义、颜色白名单与菜单结构测试；在 `crates/notebook/tests/core.rs` 增加网页图标、条目颜色和备份往返测试。先运行并确认因功能缺失失败。
2. 在 `ui/web/page-links.mjs` 实现条目识别、图标及颜色渲染；在 `ui/web/app.mjs` 接入紧凑条目、六点菜单、普通页面侧边预览。保留正文内联链接和拖动。
3. 在 `ui/web/page-menu.mjs` 与 `ui/web/app.mjs` 实现操作搜索、转换、文字色、背景色、图标、收藏、重命名、打开方式、复制链接、创建副本、移动及回收。新增文案进入 `ui/web/i18n.mjs`；手机菜单保持视口内可滚动。
4. 在 `crates/notebook/src/html_import.rs` 和 `crates/notebook/src/import.rs` 保留网页原图标及明确条目样式；本地图标附件复用资产存储，结构化备份重新映射引用。原始源信息保留。
5. 在 `tests/e2e/page-links.mjs` 通过隔离工作区验证菜单选择实际保存、刷新后保留、页面切换与侧边预览、锁定保护、打开新选项卡及手机边界。运行 `npm test`、`npm run check`、核心测试及相关数据库界面回归。
6. 请求独立代码审查，处理重要问题；追加本日记录和使用说明。构建苹果桌面应用，更新本地产物并核对资源一致性。移动端不在本机编译；不推送远程仓库。

**边界：** 智能操作按用户已有安排稍后接入；未配置的智能菜单不伪装可执行。普通副本沿用现有页面副本语义；导出未包含的样式无法凭截图准确恢复，可在菜单中重新设置。
