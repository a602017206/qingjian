# 安卓认证持久化云端验证与发布

1. 沿用本机已验证的工作区安全认证，确认安卓使用系统密钥库加密保存，不写入笔记或同步仓库。
2. 为仅云端使用的安卓启动测试包增加隔离测试开关，以匿名测试条目验证保存、进程结束后重新读取、删除及再次启动仍为空；正式安装包不启用此开关。
3. 在安卓十六及十六千字节页模拟器执行真实进程重启验证，测试日志不输出用户名和令牌。移动原生编译全部在云端执行。
4. 升级统一版本至零点零点六，补充中文发布说明和使用指南，检查本地共享测试、代码、文档及发布配置。
5. 提交并推送，通过云端构建和验证后发布新标签版本，保留既有安卓签名；核验全部资产和下载地址，交付可覆盖升级的安卓安装包。
