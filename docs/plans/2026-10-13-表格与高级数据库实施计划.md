# 表格与高级数据库实施计划

**目标：** 让用户直接发现并创建数据库，在普通页面插入简易表格，并实现多选、基础公式、跨数据库关联和汇总。

**架构：** 沿用同一套跨平台界面与 Rust 文件存储。数据库计算使用所有平台共享的纯函数模块，计算结果实时派生，不覆盖原始输入。所有关联使用稳定工作区页面及记录标识，只引用当前工作区的数据库。

**技术选型：** 共享网页模块、受控公式语法解析、已有结构化笔记格式和 Tauri 系统接口。

## 实施步骤

1. 增加失败测试，覆盖属性数值计算、条件表达式、依赖循环、禁止脚本、关联汇总、缺失记录、简易表格往返。
2. 实现共享数据库计算模块：数值运算、比较、条件、文本与集合基础函数；不使用动态脚本执行。
3. 实现多选属性、跨数据库记录关联、计数及数值汇总，支持公式引用汇总结果。
4. 增加「新建数据库」和页面内容菜单的直接入口，补齐普通简易表格编辑、行列增删和 Markdown 导出。
5. 增加属性配置、记录详情、数据库计算错误提示、日历与图库视图，保留已有表格、看板和列表。
6. 使用真实界面验证新增入口、计算刷新、关联选择、保存与刷新、窄屏以及旧数据库兼容。
7. 更新中文功能范围和使用指南，将所有修改追加到当天原有记录文件。

## 数据与兼容约定

- 简易表格使用内容块正文中的标准 Markdown 表格保存，保持现有文件结构兼容。
- 多选和关联的单元格使用序列化标识数组保存，仍满足现有记录值为字符串的格式约定。
- 公式与汇总配置保存在属性定义中。计算值为派生数据，错误不覆盖已保存的用户输入。
- 本轮实现基础公式子集，不能宣称完整兼容 Notion 的全部公式、自动化、人员权限和协作功能。
- 首版公式与汇总的派生值导出另提供计算结果表格；完整备份继续保存原始配置、记录和引用。

## 验收

同一个数据库可以在多种视图中编辑，修改单价或数量后金额自动变化；关联项目中的任务后可统计任务数量和数值。错误引用与循环依赖可见且不导致工作区不可用。普通页面的表格能够编辑并在刷新后保留。
