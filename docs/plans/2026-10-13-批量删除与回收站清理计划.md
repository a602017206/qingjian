# 批量删除与回收站清理计划

**目标：** 删除后保持列表滚动位置，支持批量移入回收站、永久删除所选回收站页面及清空回收站，并显示实际释放空间。

**架构：** 共享界面保留滚动状态与页面选择。核心新增批量回收和清理预览，确认清理时重新核对页面版本及附件清单。只允许永久删除已在回收站的页面，保留剩余页面使用的附件；不改写或强推 Git 历史。

## 实施步骤

1. 使用真实文件、共享附件和层级页面增加失败测试，覆盖批量去重、非法标识拒绝、预览确认、活动页面保护、过期预览拒绝和空间统计。
2. 实现批量回收及永久删除，预先检查所有目标，删除后报告已完成数量、释放字节和可能的失败。清理附件前核对剩余页面引用。
3. 保留版本历史；恢复历史页面时从对应提交补回需要的历史附件。
4. 增加侧栏和工作台批量管理、所选项确认、回收站永久删除及清空入口。永久操作必须先展示数量、附件和空间预览，明确无法从回收站恢复。
5. 修复整体重绘造成的滚动跳顶，分别维护侧栏和当前主页面位置，并尽量保留可见页面的位置。
6. 用隔离界面验证长列表删除、批量移入、恢复与永久清理，检查空间统计和原有菜单、布局流程。
7. 更新中文指南、验证报告与当天唯一日志，重新构建苹果桌面交付；移动原生构建仍只留给云端。
