# 轻笺官方网站与 GitHub Pages 发布计划

**目标：** 在当前仓库交付无需框架、无需构建的官方网站，并实际发布至 GitHub Pages，在 README 提供入口与维护方法。

**架构：** 独立 `website/` 目录，原生 HTML、CSS、ES modules。文案由简体中文、繁体中文、英文字典管理；官网主题为纸白、夜航、青庭。Three.js 固定版本连同许可证托管在本站，静态正文与 WebGL 动效隔离，低动态偏好和 WebGL 不可用时仍能阅读与下载。

**技术：** HTML、CSS、JavaScript、Three.js、Playwright、GitHub Actions、GitHub Pages。

## 视觉与内容

- 主题色：纸白 `#f7f8fc`、墨蓝 `#202c48`、鸢尾 `#6558d9`、青绿 `#338d7c`、雾紫 `#e9e6fa`。夜航与青庭通过 CSS 变量和 Three.js 材质一起切换。
- 标题使用系统中文衬线字体与系统西文衬线字体，正文使用系统无衬线字体，避免远程字体依赖。
- 以“悬浮纸页与想法星轨”为首屏标志，展示纸张、内容块与连接的关系；真实应用截图展示编辑器、数据库与手机界面。
- 页面包含产品介绍、真实截图切换、功能、工作区与迁移、平台下载、常见问题、源码和文档入口。
- 准确区分正式版 0.0.6 与源码/测试版 0.0.7，自动同步、数据库批量操作和桌面常驻明确标为测试构建；不承诺实时协作或完整第三方格式兼容。官网三语言不代表客户端新增英语。

## 实施顺序

1. 新建 `website/index.html`、`styles.css`、`app.mjs`、`i18n.mjs`、`scene.mjs` 与静态资源；复用仓库匿名截图并优化体积，增加本地固定版本 Three.js 和许可证。
2. 实现三主题、三语言、截图切换、移动导航、动效暂停、键盘访问、偏好记忆和静态降级；不触碰客户端存储与同步逻辑。
3. 新增 `scripts/check-website.mjs` 与 `tests/e2e/website.mjs`，验证字典完整性、站内资源、平台下载、桌面与手机布局、WebGL 实际渲染、主题和语言持久化、低动态及 WebGL 失败降级。
4. 新建 `.github/workflows/pages.yml`，只上传 `website/`，独立于客户端打包。配置 Pages 来源为 Actions。
5. 更新 README 官网、预览、测试及自动部署说明，追加当天唯一日记；只提交本任务文件，保留已有未提交的编辑器工作。
6. 推送官网提交，等待 Pages 发布成功，访问线上页面核对资源、交互与公开地址，再记录发布结果。

## 验收命令

```bash
node scripts/check-website.mjs
node tests/e2e/website.mjs
node scripts/check-docs.mjs
git diff --check
```

使用本地隔离静态服务器验证项目子路径；同时在 GitHub Actions 执行官网检查与浏览器回归。发布后检查 HTTP 状态及线上浏览器渲染。当前工作区已有其他任务的未提交修改，本任务仅选择性提交官网相关文件。
