# 官网交互动效增强

用户已明确要求增强功能卡片中的 Three.js 动效，并让首屏中央纸页可拖动旋转；沿用官网直接发布至 GitHub Pages 的授权。

## 设计与实施

- 首屏：中央纸页绕自身旋转，背景轨道继续保持环境动效；鼠标和横向触摸拖动、松手阻尼惯性、复位按钮、方向键和 Home 键。俯仰限制在正负 1.1 弧度，避免上下翻转；手机保留竖向滚动。暂停及减少动态时只响应主动操作，不产生自动惯性。
- 卡片：内容块搭建、三列看板流转、想法节点连接、版本轨迹四个真实 Three.js 场景。四卡片共用一个透明 WebGL 渲染器，按实际 DOM 区域裁剪；不影响正文、截图或下载点击。
- 性能：卡片靠近视口时才加载；首屏和卡片分别离屏、隐藏标签停止渲染，卡片限制帧率与像素倍率；不引入远程依赖。
- 外观和文案：复用三套主题材质，卡片文字从现有三语言字典生成纹理，新增操作文案进入字典。全站共用暂停偏好，功能区也有暂停入口。
- 降级：WebGL 不可用或上下文丢失时回到原有 HTML/CSS 图形，关闭无效控制，保持阅读和下载；完全无脚本也可使用原有内容。

## 文件与验证

`website/rotation.mjs` 单独维护拖动角度和惯性；`scene-kit.mjs` 共享配色与几何；`scene.mjs` 接入首屏交互；`feature-scenes.mjs` 管理共享卡片渲染。页面、样式、字典和官网维护说明随之更新。

先验证四项旋转单元测试和新增卡片浏览器断言在旧实现失败，再实施。浏览器验证真实画布、鼠标与触摸、暂停下操作、复位、键盘、四场景共享画布、三主题三语言、手机布局、滚动、降级与减少动态。官网工作流加入旋转单元测试，通过后选择性提交并正常推送，不提交并行客户端改动。
