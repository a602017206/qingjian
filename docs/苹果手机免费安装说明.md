# 苹果手机免费安装说明

轻笺提供两种不同的免费构建产物。它们都在云端构建，本机不执行移动端原生编译。

| 产物 | 用途 | 能否直接安装到手机 |
| --- | --- | --- |
| `qingjian-ios-simulator-arm64.zip` | 在苹果自研处理器电脑的开发工具模拟器中运行 | 不能，这是模拟器应用 |
| `qingjian-ios-unsigned-arm64.ipa` | 使用者自行签名后在手机测试 | 不能直接安装，必须重新签名 |

## 使用免费账号重新签名

可以使用第三方免费侧载工具的经典版本，由自己的苹果账号签名并安装未签名包。例如参考[经典侧载工具官方入门说明](https://faq.altstore.io/altstore-classic/your-altstore)，按其官方指引在电脑安装配套工具、连接手机，再导入本仓库版本页下载的未签名包。

免费账号安装的应用通常七天后过期，需要定期刷新签名；同时可激活的侧载应用数量也有限。开发者模式、设备信任、可用权限及系统限制以设备和工具实际提示为准。这个流程不需要购买开发者计划，但需要维护自己的签名；不能宣传为长期免签、直接从浏览器安装或应用商店发布。

账号和密码只应在使用者选定的工具中按官方指引处理，不要提交到轻笺仓库、笔记、问题反馈或云端机密配置。项目不会代签、不收集账号，也不提供他人的共享证书。尚未完成真机安装与全部功能验收，出现兼容问题时请报告系统和工具版本。

本项目的移动原生构建仍然只允许在云端执行，因此不提供要求用户在本项目本机重新编译的安装步骤。已有付费证书时可以另行配置正式分发流程，不影响当前免费测试产物。
