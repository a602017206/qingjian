# 轻笺零点零点七测试版

本版本仅提供测试安装文件，未创建版本标签或正式发布。正式公开版仍为零点零点六。

## 本轮修复

- 中文输入法组词回车时，数据库属性搜索不再误创建或选择选项。
- 取消输入法候选时，记录侧览保持打开和输入焦点；完成组词后仍可正常退出并保存。
- 内容块和菜单兼容按键码 `229`，避免确认候选时拆分正文或触发命令。
- 内容块菜单搜索及键盘导航更新结果时保留原输入框，避免打断组词。

测试包也包含此前尚未正式发布的自动同步、数据库记录批量操作、普通多行块排版稳定和桌面常驻功能。仍沿用现有数据格式与认证方式。

## 安装和测试

升级前请在设置中导出轻笺结构化备份，退出旧版后覆盖安装。不要卸载安卓应用或删除工作区目录。安卓继续使用原固定签名；苹果自研处理器桌面包包含中文首次打开说明，使用免费临时签名。

建议依次检查：

1. 在内容块菜单中用中文输入法搜索“折叠”，确认候选后继续输入；正常回车可插入内容块。
2. 在数据库属性选项搜索中输入新中文词语，首次回车仅确认候选，再次正常回车才创建或选择选项。
3. 打开记录侧览并编辑正文，取消候选时侧览和焦点保留；完成组词后正常退出，重新打开核对保存内容。
4. 长文、缩进和末尾空行之间切换编辑，核对光标、邻近块和滚动位置。
5. 使用自己的测试笔记在两台设备之间往返同步，覆盖离线编辑、联网补传和同篇冲突选择。无需发送笔记原文或令牌。
