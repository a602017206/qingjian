# 表格与高级数据库指南

## 两种表格

简易表格用于排版，比如对照表、信息清单和读书摘录。打开普通页面，点击「添加内容块」或输入斜线，选择「简易表格」。单元格支持直接编辑、多行内容和行列增删，保存后可以重新打开继续编辑。表格正文以 Markdown 保存，可以随页面导出。

数据库用于需要属性、筛选、计算和关联的数据。工作台和导航底部提供「新建数据库」入口，普通页面的内容菜单中也可以「添加数据库」。已有正文会保留，不会被数据库替换。也可在模板中选择「高级数据库示例」直接体验。

## 数据库的五种视图

- 表格：适合批量编辑，点击属性标题排序，点击设置图标调整属性。
- 看板：选择单选属性作为分组，支持拖动卡片改变状态；手机可以直接编辑状态。
- 列表：紧凑展示同一批记录。
- 图库：以卡片查看属性，点击标题打开记录详情。
- 日历：选择日期属性，按月份显示记录；没有有效日期的记录在下面保留展示。

视图展示同一份记录，切换视图不复制数据。当前视图选择、筛选和排序为当前会话状态，尚未实现 Notion 的多个命名视图与复合条件筛选。

## 属性和记录详情

支持文本、数字、单选、多选、日期、复选框、网址、关联、汇总和公式。新增属性时按类型填写配置；已有属性可以通过表头设置修改名称、选项与计算规则。

点击第一列的展开按钮，或图库卡片标题，打开记录详情。可以编辑属性和记录正文；正文当前为文本编辑，还不是完整的嵌套块页面。输入会自动保存。

数据库第一列保留为记录的主要名称，不通过界面删除。更换其他属性类型会保留原始单元格值；如果新类型无法解释这些值，需要手动调整。重命名被公式引用的属性后，也需要更新公式里的名称，或者直接通过稳定属性标识引用。

## 公式示例

先添加两个数字属性「单价」和「数量」，再添加公式属性「金额」：

```text
prop("单价") * prop("数量")
```

当单价为二十五、数量为四时，金额为一百；修改数量后结果立即更新。计算结果是派生值，不能直接写入原始单元格。

条件示例：

```text
if(prop("金额") >= 100, "达标", "继续")
```

日期差示例：

```text
dateBetween(parseDate("2026-10-13"), parseDate("2026-10-10"), "days")
```

可以点击公式配置下方的属性名称插入引用。

## 已支持的公式范围

基础运算包括加、减、乘、除、取余、比较、布尔运算和条件选择。函数包括属性引用、条件、布尔判断、空值、长度、包含、文本拼接、文本及数值转换、取整、绝对值、求和、平均、最小值、最大值、集合连接、日期解析、日期差、日期格式化、现在和今天。

对应函数名称保留英文，属于可执行表达式语法：

```text
prop if and or not empty length contains concat format toNumber
round floor ceil abs min max sum average join
parseDate dateBetween formatDate now today
```

日期差单位支持天、时、分、秒，对应表达式参数：

```text
days hours minutes seconds
```

日期格式化当前支持标准的年、月、日标记。公式长度、嵌套、引用数量和输出文本有上限；原始内容不会因计算错误被覆盖。

当前不支持任意脚本、对象访问、函数定义、正则表达式函数、变量绑定、列表映射、人员对象及完整的 Notion 公式语言。循环依赖、除以零、引用丢失、无效日期和溢出会在单元格中显示错误。

## 关联与汇总

例如用「项目」关联「任务」：

1. 创建任务数据库，添加名称和数字属性「工时」，录入两条任务。
2. 创建项目数据库，新增「关联」属性，选择任务数据库作为目标。
3. 点击项目的关联单元格，选择需要关联的任务。
4. 新增「汇总」属性，选择该关联属性；数量汇总直接计算关联记录数，求和与平均等需要再选择目标属性。
5. 公式可以引用汇总结果，例如总工时乘以单价。

关联采用稳定的数据库页面标识和记录标识，不依赖显示名称。恢复完整备份时会重映射数据库页面标识，并保留记录引用。目标数据库或记录删除后，引用会明确标记为失效，不静默忽略，也不把丢失内容当作零。

目前支持同一工作区中的单向关联；不自动在目标数据库创建双向反向属性，不跨 Git 仓库关联。汇总支持数量、求和、平均、最小值、最大值、原始值和唯一值。

## 导出与备份

数据库工具栏提供「导出计算结果」，生成包含公式和汇总结果的 CSV。存在计算错误时会停止结果导出，避免把错误当正常数据。

完整备份仍以原始记录、公式、关联及汇总配置为准，可以重新导入继续计算。备份中附带的基础 CSV 只用于原始数据阅读；需要派生结果时使用专门的计算结果导出。

Notion 的普通导出文件通常只保存部分已显示的结果，不包含完整公式和关联规则。因此不能承诺自动还原它的全部数据库逻辑；迁移后需要按目标结构配置高级属性。

## 后续范围

命名视图、复合筛选、多层排序、双向关联、关联页面块、完整公式兼容、自动化、云端人员权限、多人实时协作仍为后续功能。现有版本已经可以完成个人知识库、项目任务统计和基础数值计算的主要流程。

功能参考：[官方关联与汇总说明](https://www.notion.com/help/relations-and-rollups)、[官方公式语法说明](https://www.notion.com/help/formula-syntax)。具体兼容范围以本文和实际测试为准。

## 状态与选项颜色

状态是独立的属性类型，单元格显示圆点和颜色，可通过下拉选择状态。单选、多选也支持彩色标签。点击表头设置，选择状态、单选或多选类型，再为各选项设置颜色；表格、看板、图库和记录详情使用同一套颜色配置。普通文本不会自动显示成标签。

表格加文本压缩导入时，明确的状态、分类、地区、平台、观看时间和优先级字段会根据名称及内容推断为对应属性；不明确的字段仍保留文本。日期中斜线转换为标准日期，分类中的多个值转换为选项数组，原始值同时保留。导入报告会提示类型经过推断。纯文本表格缺少原始颜色配置，初始颜色由应用分配，之后可以手动调整。

## 整理已有导入

已经导入为文本的影视表格无需重新导入。打开目标数据库，点击编辑工具栏的「整理导入数据」，检查字段类型和子页面归属建议，再选择应用。此入口只整理当前数据库；「设置 → 数据 → 整理导入数据」可检查整个工作区。

子页面建议依据数据库记录名称与没有父级的笔记唯一匹配生成。同名笔记、多个可能父级和可能形成循环的关系不会自动建议；可以在笔记「所属页面」中手动选择。整理不会删除笔记或覆盖正文，不会改动已经配置好的属性；应用前会建立本地版本。等待刷新和批量保存时暂时保护编辑及工作区切换，保存仍执行版本校验；中途失败会报告已保存数量。

同一个导出包可能包含展示表格和完整字段表格。只有同一导出标识、字段包含关系和记录内容均可核对时，合并为一个数据库；保留完整字段和全部记录，初始字段及记录次序采用展示表格，其他字段及记录继续保留。不能核对的文件分别保留，不猜测或删除。父文件带标识、子目录只使用页面名称时，会通过唯一目录候选归属；多个候选时明确报告歧义。

## 页面宽度与导航

正文默认使用窗口的可用宽度，右侧页面信息默认收起。顶部的宽度按钮可以切换阅读宽度与全宽显示，信息按钮可以展开目录、反向链接和时间信息。宽度偏好保存在当前设备，切换不会改动笔记内容。

桌面顶部菜单按钮和侧栏右上角关闭按钮可以收起、重新展开侧栏；桌面收起状态在刷新后保持。手机继续使用抽屉导航。导航树点击父页面左侧箭头展开或收起子页面；页面正文底部的子页面区也默认折叠。

工作台默认只显示顶层页面，勾选「包含子页面」可以查看全部层级。输入搜索、选择标签或查看收藏时会检索子页面，收起目录不会让内容无法搜索。


## 表格记录与原始子页面

导入父数据库后，会结合记录名称及文本页面导出属性核对原始子页面。只有双方唯一对应时才建立打开关系；同名页面不会互相覆盖。点击记录展开按钮可以定位对应子页面，原始正文和属性段保留。没有唯一对应的记录仍使用普通记录详情，并在报告中说明。

子页面会读取对应数据库行，显示可编辑的结构化属性；修改后保存到父数据库。完整核对的原始属性段不再重复展示，原文及来源值仍保留。完整备份会同时保存父子层级及记录打开关系，恢复时重映射页面标识。

旧版本已经平铺的数据不会因升级自动删除或合并。建议先在空工作区导入确认结构，原工作区的错误导入可使用批量回收处理，避免重复导入造成混淆。

## 完整本地属性

属性设置提供可搜索的图标类型菜单，包含文本、数字、选择、多选、状态、日期、人员、文件和媒体、复选框、网址、电子邮件、电话、函数、关联关系、汇总、创建时间、创建者、上次编辑时间、上次编辑者、按钮、位置和编号。表格与子页面共用编辑控件、类型定义和颜色。名称、可见性、布局仍在属性名称菜单中设置。

人员使用当前字段的本地名单，可在属性设置中增删名称，记录支持选择多人。文件和媒体可上传本地附件、添加网页链接、查看及移除；附件仍按内容摘要保存，不自动下载远程地址。位置记录手动地址和可选经纬度；坐标须成对且在有效范围内。邮件、电话只编辑文本，不自动发信或拨号。

创建和编辑时间、作者及编号为只读属性。本机新建及编辑的作者为“本机用户”，导入文件缺少原作者时显示未知。数据库子页正文编辑也计入其上次编辑信息。修改字段名称或布局不会更新记录编辑时间。编号支持前缀，删除记录后不复用，备份恢复后继续递增。

按钮支持给当前记录的一个可写属性赋值，点击后展示目标和值并确认。可修改文本、数字、选择、多选、状态、日期、人员、复选框、网址、邮件和电话；系统属性、标题及计算属性不能作为目标。按钮不执行脚本或外部操作。函数与关联汇总继续采用本文规定的本地兼容范围。

智能总结和翻译稍后接入模型接口，本轮没有智能填充。导入根据显式导出类型恢复属性；导出缺失的类型、公式逻辑、云端权限或作者不会被伪造。未知字段继续保留原类型与原始内容。

## 对齐数据库记录操作

记录详情改为右侧预览，父数据库的表格及页面保持原有位置。选中记录在左侧标记，可连续打开不同记录；右侧编辑属性及正文。查看其他记录和关闭前沿用串行保存及版本检查，不覆盖未保存输入。直接从导航打开子页继续使用完整页面。

选项菜单提供搜索和彩色标签；单选和状态点击后立即生效，多选、人员及关联连续选择时即时保存。新选项可从搜索菜单创建，仍记录在当前数据库字段定义中，不关联云端人员权限。字段配置、位置及媒体表单位于相邻弹层，窗口变化保留输入。手机使用底部弹层和全宽记录面板，编辑逻辑共用。
